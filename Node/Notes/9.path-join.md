# 9. path.join

## What this script does
- Uses `path.join` to build a cross-platform file path.
- Combines `__dirname` with folder and file names.

## Example code
```js
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const filePath = path.join(__dirname, "data", "products", "products.json");
console.log(filePath);
```

## Why use path.join?
- Automatically handles `/` vs `\` on different operating systems.
- Safer than manually concatenating strings.

## How to run
```bash
node 10.pathJoin.js
```
