# 3. process globals

## What is `process`?
- `process` is a global object in Node.js.
- It provides information about the current Node process and environment.

## Common `process` properties
- `process.version` - current Node.js version
- `process.cwd()` - current working directory
- `process.platform` - operating system platform
- `process.pid` - current process ID

## Example
```js
console.log(process.version);
console.log(process.cwd());
console.log(process.platform);
console.log(process.pid);
```

## Why it matters
- Use `process` to inspect runtime details.
- Useful for debugging and environment-aware behavior.
- Many CLI tools and servers depend on `process` values.
