# 6. Environment variables

## What are environment variables?
- Key/value pairs provided by the system or shell.
- Available in Node through `process.env`.

## Example usage
```js
console.log(process.env.USERNAME);
console.log(process.env.OS);
console.log(process.env.TEMP);
console.log(process.env.PORT);
```

## Notes
- `process.env` is an object containing all environment variables.
- Values are always strings.
- Common environment variables include `PORT`, `USERNAME`, and `HOME`.

## Why use them?
- Keep configuration outside code.
- Useful for secrets, port numbers, and environment-specific settings.
