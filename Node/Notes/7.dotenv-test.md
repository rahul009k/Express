# 7. dotenv with a test file

## What this script does
- Loads environment variables from a custom `.env.test` file.
- Uses `dotenv.config({ path: ".env.test", override: true })`.
- Prints the values from `process.env`.

## Example code
```js
import dotenv from "dotenv";
dotenv.config({
  path: ".env.test",
  override: true
});

console.log(process.env.PORT + " " +
  process.env.USERNAME + " " +
  process.env.COURSE);
```

## Why use a custom path?
- Keeps separate configurations for test, development, and production.
- `override: true` replaces existing values if already set.

## How to run
```bash
node 07.testEnv.js
```

## Useful for
- Testing with a different `.env` file.
- Loading environment variables specific to a test environment.
