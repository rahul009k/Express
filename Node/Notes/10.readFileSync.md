# 10. readFileSync

## What this script does
- Reads a file synchronously using `fs.readFileSync`.
- Blocks execution until the file is fully read.

## Example code
```js
import fs from "fs";
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const filePath = path.join(__dirname, "DATA", "users.txt");

const user = fs.readFileSync(filePath, "utf8");
console.log(user);
```

## Sync vs Async
- `readFileSync` blocks the event loop — fine for scripts, avoid in servers.
- Use `fs/promises` for non-blocking async reads.

## How to run
```bash
node 11.readFileSync.js
```
