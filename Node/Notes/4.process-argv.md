# 4. process.argv

## What is `process.argv`?
- `process.argv` is an array of command-line arguments passed to Node.
- It includes:
  - index 0: path to the Node executable
  - index 1: path to the script file
  - index 2+: actual user arguments

## Example
```js
console.log(process.argv);
```

## Use case
- Read values passed from the terminal.
- Build CLI tools or simple scripts.

## Example output
```bash
node 03.argumentsDemo.js hello world
```
- `process.argv[2]` -> `hello`
- `process.argv[3]` -> `world`
