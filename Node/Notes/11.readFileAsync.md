# 11. readFile (Async)

## What this script does
- Reads a file asynchronously using `fs/promises`.
- Splits the content into a trimmed, filtered array.

## Example code
```js
import fs from "fs/promises";
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const filePath = path.join(__dirname, "DATA", "users.txt");

const file = await fs.readFile(filePath, "utf8");
console.log(file);

const list = file.split("\n").map(name => name.trim()).filter(Boolean);
console.log(list);
```

## Why use async?
- Non-blocking — doesn't freeze the event loop.
- `await` makes async code read like synchronous code.

## How to run
```bash
node 12.readFileAsync.js
```
