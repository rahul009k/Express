# 15. readdir (Read Directory)

## What this script does
- Reads all file names in a directory using `fs.readdir`.
- Filters files by extension (`.json`, `.txt`).
- Logs each file's name without its extension using `path.basename`.

## Example code
```js
import fs from "fs/promises";
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const folderpath = path.join(__dirname, "DATA");

const result = await fs.readdir(folderpath);
console.log(result);

const jsonFiles = result.filter(x => x.endsWith(".json"));
const txtFiles = result.filter(x => x.endsWith(".txt"));

for (const file of result) {
    const fileName = path.basename(file, path.extname(file));
    console.log(fileName);
}
```

## Useful for
- Listing files in a folder dynamically.
- Filtering files by type for batch processing.

## How to run
```bash
node 16.readDirectory.js
```
