# 8. import.meta & __filename / __dirname (ESM)

## What this script does
- Uses `import.meta.url` to get the current file's URL.
- Converts it to a file path using `fileURLToPath`.
- Derives `__dirname` using `path.dirname`.

## Example code
```js
import { fileURLToPath } from "url";
import { dirname } from "path";

const __filename = fileURLToPath(import.meta.url);
const __dirname = dirname(__filename);

console.log(import.meta.url);
console.log(__filename);
console.log(__dirname);
```

## Why use this?
- ES Modules don't have `__filename` or `__dirname` by default.
- `import.meta.url` is the ESM equivalent of `__filename`.

## How to run
```bash
node 09.metaDemo.js
```
