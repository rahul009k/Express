# 14. mkdir

## What this script does
- Creates a new directory using `fs.mkdir`.
- Uses `{ recursive: true }` to avoid errors if the folder already exists.

## Example code
```js
import fs from "fs/promises";
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const folderpath = path.join(__dirname, "Logs");

await fs.mkdir(folderpath, { recursive: true });
console.log("Logs folder created successfully.");
```

## Why use `recursive: true`?
- Without it, Node throws `EEXIST` if the folder already exists.
- With it, the call is safely ignored if the folder is already there.

## How to run
```bash
node 15.mkdir.js
```
