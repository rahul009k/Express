# 12. writeFile

## What this script does
- Creates (or overwrites) a file with `fs.writeFile`.
- Writes a string of student names to `Students.txt`.

## Example code
```js
import fs from "fs/promises";
import path from "path";
import { fileURLToPath } from "url";

const students = "rahul \n Rohan \n Mohan";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const filePath = path.join(__dirname, "DATA", "Students.txt");

await fs.writeFile(filePath, students);
console.log("File created successfully");
```

## Note
- If the file already exists, `writeFile` overwrites it completely.
- Use `appendFile` to add content without overwriting.

## How to run
```bash
node 13.writeFile.js
```
