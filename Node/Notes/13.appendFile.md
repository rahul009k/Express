# 13. appendFile

## What this script does
- Reads an existing file, then appends a new line to it using `fs.appendFile`.

## Example code
```js
import fs from "fs/promises";
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const filePath = path.join(__dirname, "DATA", "students.txt");

await fs.appendFile(filePath, "\nVirat");
console.log("Added New student");
```

## writeFile vs appendFile
- `writeFile` — overwrites the entire file.
- `appendFile` — adds content at the end without touching existing data.

## How to run
```bash
node 14.appendFile.js
```
