# 5. Validate command-line arguments

## What this script does
- Reads command-line arguments from `process.argv`
- Checks whether `Name`, `Age`, and `City` are provided
- Prints a message if any required value is missing

## Example script behavior
```js
let isUndefined = false;
for (let i = 2; i <= 4; i++) {
  if (process.argv[i] == undefined) {
    isUndefined = true;
  }
}
if (isUndefined == true) {
  console.log("Please provide Name, Age and City.");
} else {
  console.log("Name: " + process.argv[2]);
  console.log("Age: " + process.argv[3]);
  console.log("City: " + process.argv[4]);
}
```

## How to run it
```bash
node 05.validateArguments.js Rahul 25 Mumbai
```

## Result when all arguments exist
- `Name: Rahul`
- `Age: 25`
- `City: Mumbai`

## Result when missing arguments
- `Please provide Name, Age and City.`

## Why this is useful
- Ensures required input is present before running the script.
- Prevents runtime errors from undefined values.
