# 16. rename (Move / Rename File)

## What this script does
- Renames or moves a file using `fs.rename`.
- Moves `StudentsData.txt` from `DATA/` to `Logs/Students.txt`.

## Example code
```js
import fs from "fs/promises";
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const oldpath = path.join(__dirname, "DATA", "StudentsData.txt");
const newpath = path.join(__dirname, "Logs", "Students.txt");

await fs.rename(oldpath, newpath);
console.log("File renamed successfully.");
```

## Note
- `fs.rename` can both rename and move a file in one call.
- The destination directory must already exist.

## How to run
```bash
node 17.renameFile.js
```
