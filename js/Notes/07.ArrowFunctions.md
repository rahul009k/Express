# 🟦 Arrow Functions

---

## 📖 Definition

Arrow functions provide shorter syntax for writing functions.

---

## ❓ Why it was introduced

They make code cleaner and easier to read.

---

## ✍️ Syntax

```javascript
const add = (a, b) => a + b;
```

---

## 💻 Code Example

```javascript
const add = (a, b) => a + b;
console.log(add(3, 4));
```

---

## 🧩 Line-by-line Explanation

- The arrow syntax creates a compact function.
