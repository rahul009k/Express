# 🟦 Functions

---

## 📖 Definition

Functions are reusable blocks of code that perform a specific task.

---

## ❓ Why it was introduced

They make programs shorter and easier to maintain.

---

## ✍️ Syntax

```javascript
function greet(name) {
    return `Hello ${name}`;
}
```

---

## 💻 Code Example

```javascript
function greet(name) {
    return `Hello ${name}`;
}
console.log(greet("Rahul"));
```

---

## 🧩 Line-by-line Explanation

- The function accepts a parameter.
- It returns a greeting string.
