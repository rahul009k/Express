# 🟦 filter()

---

## 📖 Definition

filter() creates a new array with elements that pass a condition.

---

## ❓ Why it was introduced

It helps select the needed values.

---

## ✍️ Syntax

```javascript
array.filter(item => item > 5);
```

---

## 💻 Code Example

```javascript
const numbers = [1, 2, 3, 4, 5];
const result = numbers.filter(n => n > 3);
console.log(result);
```

---

## 🧩 Line-by-line Explanation

- Only values that satisfy the condition are kept.
