# 🟦 Async/Await

---

## 📖 Definition

Async/Await is a modern JavaScript syntax used to work with Promises in a cleaner and more readable way.

---

## ❓ Why it was introduced

It makes asynchronous code look more like regular synchronous code, which is easier to understand and maintain.

---

## ✍️ Syntax

```javascript
async function demo() {
    const result = await promise;
    console.log(result);
}
```

---

## 💻 Code Example

```javascript
async function demo4() {
    console.log("1");

    try {
        const value = await Promise.resolve("2");
        console.log(value);

        throw new Error("Oops");
    } catch (error) {
        console.log(error.message);
    }

    console.log("3");
}

console.log("Start");
demo4();
console.log("End");
```

---

## 🧩 Line-by-line Explanation

- async makes a function return a Promise.
- await pauses the function until the Promise resolves.
- try/catch is used to handle errors safely.
- console.log() prints the values in sequence.

---

## 🔑 Key Points

- async/await makes Promise-based code easier to read.
- await only works inside async functions.
- Use try/catch for error handling.

---

## ⚠️ Common Mistakes

- Forgetting to use async before the function.
- Using await outside an async function.
- Not handling errors properly.

---

## ✅ Best Practices

- Use async/await for cleaner asynchronous code.
- Keep functions small and easy to read.
- Always handle errors with try/catch.

---

## 🌍 Real-world Use Cases

- Fetching data from APIs
- Reading files
- Handling timers and background operations
