# 🟦 Promises

---

## 📖 Definition

Promises handle asynchronous work such as timers, API calls, and file operations.

---

## ❓ Why it was introduced

They make async code easier to read and manage than nested callbacks.

---

## ✍️ Syntax

```javascript
const promise = new Promise((resolve, reject) => { resolve("Done"); });
```

---

## 💻 Code Example

```javascript
const promise = new Promise((resolve, reject) => {
    resolve("Done");
});
promise.then(result => console.log(result));
```

---

## 🧩 Line-by-line Explanation

- resolve() marks the promise as successful.
- .then() runs on success.
