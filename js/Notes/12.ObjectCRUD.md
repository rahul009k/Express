# 🟦 Object CRUD

---

## 📖 Definition

CRUD means Create, Read, Update, and Delete operations on objects.

---

## ❓ Why it was introduced

These operations are common when working with data.

---

## ✍️ Syntax

```javascript
const user = { name: "Rahul" };
user.age = 25;
```

---

## 💻 Code Example

```javascript
const user = { name: "Rahul" };
user.age = 25;
delete user.age;
console.log(user);
```

---

## 🧩 Line-by-line Explanation

- Create by adding a property.
- Read by accessing it.
- Update by changing its value.
- Delete by removing it.
