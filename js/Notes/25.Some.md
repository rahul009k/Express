# 🟦 some()

---

## 📖 Definition

some() checks whether at least one element passes a test.

---

## ❓ Why it was introduced

It is useful for existence checks.

---

## ✍️ Syntax

```javascript
array.some(item => item > 10);
```

---

## 💻 Code Example

```javascript
const numbers = [2, 4, 6];
console.log(numbers.some(n => n > 5));
```

---

## 🧩 Line-by-line Explanation

- It returns true if any item passes the test.
