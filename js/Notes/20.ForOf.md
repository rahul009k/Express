# 🟦 for...of Loop

---

## 📖 Definition

The for...of loop iterates over values in arrays or other iterables.

---

## ❓ Why it was introduced

It is simpler than a traditional loop for collections.

---

## ✍️ Syntax

```javascript
for (const item of items) {
    console.log(item);
}
```

---

## 💻 Code Example

```javascript
const items = [10, 20, 30];
for (const item of items) {
    console.log(item);
}
```

---

## 🧩 Line-by-line Explanation

- Each value is assigned to item one by one.
