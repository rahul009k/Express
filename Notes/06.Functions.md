# Functions

## 📖 Definition

A function is a reusable block of code that performs a specific task. You define it once and call it whenever needed. Functions help avoid repetition and make code organized and readable.

```javascript
function greet(name) {
    console.log("Hello, " + name + "!");
}

greet("Rahul");
```

Output

```
Hello, Rahul!
```

---

# Why do we need Functions?

Without functions you would repeat the same code.

```javascript
console.log("Hello, Rahul!");
console.log("Hello, Amit!");
console.log("Hello, Neha!");
```

With a function you write it once and reuse it.

```javascript
function greet(name) {
    console.log("Hello, " + name + "!");
}

greet("Rahul");
greet("Amit");
greet("Neha");
```

# Function with Return Value

```javascript
function add(a, b) {
    return a + b;
}

let result = add(5, 10);

console.log(result);
```

Output

```
15
```

---

# Function with Multiple Operations

```javascript
function multiply(a, b) {
    return a * b;
}

let product = multiply(5, 10);

console.log(product);
```

Output

```
50
```

---

# Function Inside a Class

```javascript
class Calculator {
    add(a, b) {
        return a + b;
    }
}

const calc = new Calculator();

const sum = calc.add(5, 10);

console.log(sum);
```

Output

```
15
```

---

# Arrow Function (Short Syntax)

```javascript
const discount = (price, discountPercentage) => {
    return price - (price * discountPercentage / 100);
};

console.log(discount(100, 20));
```

Output

```
80
```

# Function Declaration vs Function Expression

## Declaration

```javascript
function add(a, b) {
    return a + b;
}
```

Can be called before it is defined (hoisted).

## Expression

```javascript
const add = function(a, b) {
    return a + b;
};
```

Cannot be called before it is defined.

---

# Parameters vs Arguments

Parameters are the names in the function definition.

```javascript
function greet(name) { }
```

Arguments are the actual values passed when calling.

```javascript
greet("Rahul");
```

---

# Best Practices

✅ Use descriptive function names.

```javascript
function calculateDiscount(price, percentage) { }
```

Instead of

```javascript
function calc(p, x) { }
```

Keep functions small and focused on one task.

Use `const` for function expressions.

```javascript
const greet = function(name) { };
```

---

# Common Mistakes

## Forgetting to return a value

Wrong

```javascript
function add(a, b) {
    a + b;
}

console.log(add(5, 10));
```

Output

```
undefined
```

Correct

```javascript
function add(a, b) {
    return a + b;
}
```

---

## Calling a function without parentheses

Wrong

```javascript
greet;
```

Correct

```javascript
greet("Rahul");
```
