# 🟪 Functions

---

## 📖 Definition

A **function** is a reusable block of code that performs a specific task. You define it once and call it whenever needed. Functions help avoid repetition and make code **organized** and **readable**.

```javascript
function greet(name) {
    console.log("Hello, " + name + "!");
}

greet("Rahul");
```

**Output**

```
Hello, Rahul!
```

---

## ❓ Why do we need Functions?

Without functions you would repeat the same code.

```javascript
console.log("Hello, Rahul!");
console.log("Hello, Amit!");
console.log("Hello, Neha!");
```

With a function you write it **once** and reuse it.

```javascript
function greet(name) {
    console.log("Hello, " + name + "!");
}

greet("Rahul");
greet("Amit");
greet("Neha");
```

---

## ✍️ Function Declaration Syntax

```javascript
function functionName(parameters) {
    // code
    return value;
}
```

## 💻 Examples from the Code

### 👋 Greet Function

```javascript
function greet(name) {
    console.log("Hello, " + name + "!");
```

**Output** → `Hello, Rahul!`

### ➕ Function with Return Value

```javascript
function add(a, b) {
    return a + b;
}

let result = add(5, 10);
console.log(result);
```

**Output** → `15`

---

### ✖️ Multiply Function

```javascript
function multiply(a, b) {
    return a * b;
}

let product = multiply(5, 10);
console.log(product);
```

**Output** → `50`

---

### 🏗️ Function Inside a Class

```javascript
class Calculator {
    add(a, b) {
        return a + b;
    }
}

const calc = new Calculator();
const sum = calc.add(5, 10);

console.log(sum);
```

**Output** → `15`

---

### 💰 Arrow Function — Discount

```javascript
const discount = (price, discountPercentage) => {
    return price - (price * discountPercentage / 100);
};

console.log(discount(100, 20));
```

**Output** → `80`

---

### ➖ Subtract Function

```javascript
function subtract(a, b) {
    return a - b;
}

const difference = subtract(10, 5);
console.log(difference);
```

**Output** → `5`

---

### 🔢 isEven Function

```javascript
function isEven(num) {
    return num % 2 == 0;
}

console.log(isEven(5));
```

## 🗂️ Types of Functions

```
Functions
│
├── 📝 Function Declaration   → function name() {}
├── 📦 Function Expression    → const name = function() {}
├── ➡️ Arrow Function         → const name = () => {}
└── 🏗️ Method                 → inside a class or object
```

---

## 🔄 Declaration vs Expression

### Declaration — can be called before definition (hoisted)

```javascript
function add(a, b) {
    return a + b;
}
```

### Expression — cannot be called before definition

```javascript
const add = function(a, b) {
    return a + b;
};
```

---

## 📌 Parameters vs Arguments

**Parameters** — names in the function definition.

```javascript
function greet(name) { }  // name is a parameter
```

**Arguments** — actual values passed when calling.

```javascript
greet("Rahul");  // "Rahul" is an argument
```

---

## ✅ Best Practices

✅ Use descriptive function names.

```javascript
function calculateDiscount(price, percentage) { }
```

❌ Instead of

```javascript
function calc(p, x) { }
```

✅ Keep functions small and focused on **one task**.

✅ Use `const` for function expressions.

---

## ⚠️ Common Mistakes

### ❌ Forgetting to return a value

```javascript
function add(a, b) {
    a + b; // ❌ no return
}

console.log(add(5, 10)); // undefined
```

```javascript
function add(a, b) {
    return a + b; // ✅
}
```

---

### ❌ Calling a function without parentheses

```javascript
greet;          // ❌ does nothing
greet("Rahul"); // ✅ calls the function
```

## 🌍 Real-world Example

```javascript
function calculateTotal(price, tax) {
    return price + (price * tax / 100);
}

const total = calculateTotal(1000, 18);

console.log(total); // 1180
```
