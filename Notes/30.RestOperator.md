# Rest Operator

## 📖 Definition

The rest operator `...` collects the remaining arguments passed to a function into a single array. It is useful when the number of arguments is unknown or variable.

---

# Why use the rest operator?

It allows a function to accept any number of arguments without using the `arguments` object. The rest operator keeps code readable and works well with array methods.

---

# Basic usage

```javascript
function showNumbers(...numbers) {
    console.log(numbers);
}

showNumbers(1, 2, 3, 4, 5);
```

Output

```
[ 1, 2, 3, 4, 5 ]
```

---

# First argument and the rest

You can combine named parameters with the rest operator. The rest parameter must be the last parameter.

```javascript
function print(first, ...others) {
    console.log(first);
    console.log(others);
}

print(10, 20, 30, 40);
```

Output

```
10
[ 20, 30, 40 ]
```

---

# Using rest with array methods

Because rest collects values into an array, you can use array methods like `reduce`, `map`, and `filter`.

```javascript
function sum(...numbers) {
    const total = numbers.reduce((acc, curr) => acc + curr, 0);
    console.log(total);
}

sum(10, 20, 30);
```

Output

```
60
```

---

# Notes

- The rest operator must appear as the last parameter in a function definition.
- The name after `...` can be any valid variable name.
- Rest works only in function parameter lists, unlike the spread operator which works in array and object literals.
