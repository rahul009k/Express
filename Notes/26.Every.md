# Array.every()

## 📖 Definition

`every()` is an array method that checks whether **all** elements in the array satisfy a given condition. It returns `true` only if every element passes, and `false` if even one element fails.

```javascript
array.every(callback)
```

---

# Why do we need every()?

When you want to verify that all elements in an array meet a condition.

Without `every()`

```javascript
let allPass = true;

for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] <= 10) {
        allPass = false;
        break;
    }
}
```

With `every()`

```javascript
const allPass = numbers.every(num => num > 10);
```

---

# Syntax

```javascript
const result = array.every(element => condition);
```

---

# Example

```javascript
const numbers = [12, 18, 25, 30];

let result = numbers.every(num => num > 10);

console.log(result);
```

Output

```
true
```

All numbers are greater than `10`, so `every()` returns `true`.

---

# Returns false When Any Element Fails

```javascript
const numbers = [12, 18, 5, 30];

let result = numbers.every(num => num > 10);

console.log(result);
```

Output

```
false
```

`5` is not greater than `10`, so `every()` returns `false`.

---

# every() Stops at First Failure

`every()` stops iterating as soon as it finds the first element that fails the condition.

```javascript
const numbers = [12, 18, 5, 30];

const result = numbers.every(n => {
    console.log("Checking:", n);
    return n > 10;
});

console.log(result);
```

Output

```
Checking: 12
Checking: 18
Checking: 5
false
```

Stops at `5` because it fails the condition.

---

# every() vs some()

| | every() | some() |
|--|--------|-------|
| Returns true when | All elements pass | At least one passes |
| Returns false when | At least one fails | None pass |
| Stops early | At first false | At first true |
| Empty array | `true` | `false` |

---

# every() on an Empty Array

```javascript
const empty = [];

console.log(empty.every(n => n > 10));
```

Output

```
true
```

> An empty array always returns `true` with `every()` — this is called vacuous truth.

---

# Best Practices

✅ Use `every()` to validate that all elements meet a requirement.

```javascript
const allAdults = users.every(user => user.age >= 18);
```

Use `some()` when at least one element needs to pass.

```javascript
const hasAdmin = users.some(user => user.role === "admin");
```

---

# Common Mistakes

## Confusing every() with some()

`every()` — all must pass.

`some()` — at least one must pass.

```javascript
const marks = [65, 72, 88, 91, 54];

console.log(marks.every(m => m >= 50));

console.log(marks.some(m => m >= 50));
```

Output

```
false
true
```

`54` fails `every()` but `some()` still returns `true`.

---

## Forgetting empty array returns true

```javascript
const empty = [];

console.log(empty.every(n => n > 100));
```

Output

```
true
```

Always handle the empty array case if needed.

# Real-world Example

```javascript
const payments = [
    { id: 1, status: "paid" },
    { id: 2, status: "paid" },
    { id: 3, status: "paid" }
];

const allPaid = payments.every(p => p.status === "paid");

if (allPaid) {
    console.log("All payments are complete");
} else {
    console.log("Some payments are pending");
}
```

Output

```
All payments are complete
```
