# Data Types

## 📖 Definition

A data type defines the kind of value that a variable can store. JavaScript is a **dynamically typed language**, meaning you don't need to specify the data type when declaring a variable. JavaScript automatically determines the type based on the assigned value.

Example

```javascript
let name = "Rahul";
let age = 24;
let isStudent = true;
```

---

# Why do we need Data Types?

Imagine storing everything as text.

```javascript
let age = "24";
```

Now if you try:

```javascript
age + 5;
```

Output

```
245
```

Instead of

```
29
```

JavaScript needs data types to know how values should behave.

---

# Categories of Data Types

JavaScript has **two categories** of data types.

```
Data Types
│
├── Primitive
│   ├── String
│   ├── Number
│   ├── Boolean
│   ├── Undefined
│   ├── Null
│   ├── Symbol
│   └── BigInt
│
└── Non-Primitive
    ├── Object
    ├── Array
    └── Function
```

---

# Primitive Data Types

Primitive values are immutable (cannot be changed directly).

## 1. String

Stores text.

```javascript
let name = "Rahul";
```

```javascript
console.log(typeof name);
```

Output

```
string
```

---

## 2. Number

Stores integers and decimal numbers.

```javascript
let age = 24;

let price = 99.99;
```

```javascript
console.log(typeof age);
```

Output

```
number
```

---

## 3. Boolean

Stores true or false.

```javascript
let isLoggedIn = true;
```

Output

```
boolean
```

---

## 4. Undefined

A variable declared but not assigned.

```javascript
let city;

console.log(city);
```

Output

```
undefined
```

---

## 5. Null

Represents an intentional empty value.

```javascript
let user = null;
```

Output

```
object
```

> **Interview Note:** `typeof null` returns `"object"` due to a historical bug in JavaScript. This behaviour is kept for backward compatibility.

---

## 6. Symbol

Creates a unique value.

```javascript
const id1 = Symbol("id");

const id2 = Symbol("id");

console.log(id1 === id2);
```

Output

```
false
```

---

## 7. BigInt

Used for very large integers.

```javascript
const number = 123456789012345678901234567890n;
```

Output

```
bigint
```

---

# Non-Primitive Data Types

These store collections or more complex data.

---

## Object

Stores key-value pairs.

```javascript
const student = {

    name: "Rahul",

    age: 24
};
```

---

## Array

Stores multiple values.

```javascript
const fruits = [

    "Apple",

    "Banana",

    "Orange"
];
```

---

## Function

Functions are objects in JavaScript.

```javascript
function greet() {

    console.log("Hello");
}
```

# Primitive vs Non-Primitive

| Primitive | Non-Primitive |
|------------|---------------|
| Immutable | Mutable |
| Stored by value | Stored by reference |
| Fixed value | Collection of values |

# Memory (Stack vs Heap)

## Stack Memory

Primitive values are stored in the stack.

```javascript
let a = 10;

let b = a;

b = 20;

console.log(a);
```

Output

```
10
```

The original value does not change.

---

## Heap Memory

Objects and arrays are stored in the heap.

```javascript
let person1 = {

    name: "Rahul"
};

let person2 = person1;

person2.name = "Amit";

console.log(person1.name);
```

Output

```
Amit
```

Both variables reference the same object.

# Type Conversion

## Implicit Conversion

```javascript
"5" + 2
```

Output

```
52
```

---

```javascript
"5" - 2
```

Output

```
3
```

---

## Explicit Conversion

Convert string to number.

```javascript
Number("100");
```

Output

```
100
```

Convert number to string.

```javascript
String(100);
```

Output

```
"100"
```

Convert to boolean.

```javascript
Boolean(1);
```

Output

```
true
```

# Best Practices

✅ Use the correct data type for the value.

```javascript
let age = 24;
```

Instead of

```javascript
let age = "24";
```

---

Prefer strict equality.

```javascript
=== 
```

Instead of

```javascript
==
```

---

Avoid unnecessary type conversion.

---

# Common Mistakes

## Confusing null and undefined

Wrong

```javascript
let user;
```

Correct

```javascript
let user = null;
```

when you intentionally mean "no value".

---

## Using ==

Wrong

```javascript
5 == "5"
```

Correct

```javascript
5 === "5"
```

---

## Forgetting typeof null

```javascript
typeof null
```

Output

```
object
```

This is expected behaviour.
