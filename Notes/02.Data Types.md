# 🟦 Data Types

---

## 📖 Definition

Data types describe the kind of value stored in a variable.

---

## ❓ Why it was introduced

They help JavaScript understand how to process the value correctly.

---

## ✍️ Syntax

```javascript
let name = "Rahul";
let age = 25;
let isActive = true;
```

---

## 💻 Code Example

```javascript
let name = "Rahul";
let age = 25;
let isActive = true;
console.log(typeof name);
```

---

## 🧩 Line-by-line Explanation

- Strings are text values.
- Numbers are numeric values.
- Booleans represent true or false.
