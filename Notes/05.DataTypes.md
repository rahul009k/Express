# 🟩 Data Types — Practice

---

## 📖 Definition

A **data type** defines the kind of value a variable can store. JavaScript is **dynamically typed** — the type is determined automatically based on the assigned value.

---

## 💻 From the Code

```javascript
const name = "rahul";                          // 🔤 string
let age = 25;                                  // 🔢 number
let isDeveloper = true;                        // ✅ boolean
let salary = 20000.50;                         // 🔢 number
let manager = null;                            // 🚫 null
let phone;                                     // ❓ undefined
const skills = ["C#", ".NET", "JavaScript"];   // 📦 object (array)
```

---

## 🔍 typeof Each Variable

```javascript
console.log(typeof name);
console.log(typeof age);
console.log(typeof isDeveloper);
console.log(typeof salary);
console.log(typeof manager);
console.log(typeof phone);
console.log(typeof skills);
```

**Output**

```
string
number
boolean
number
object
undefined
object
```

---

## ⚠️ Why typeof null returns "object"

```javascript
let manager = null;

console.log(typeof manager); // "object"
```

> 🐛 This is a **historical bug** in JavaScript. `null` is not actually an object, but `typeof null` returns `"object"` for **backward compatibility**.

---

## ⚠️ Why typeof array returns "object"

```javascript
const skills = ["C#", ".NET", "JavaScript"];

console.log(typeof skills); // "object"
```

> 💡 Arrays are a **type of object** in JavaScript. Use `Array.isArray()` to properly check for arrays.

```javascript
console.log(Array.isArray(skills)); // true
```

## ✅ Best Practices

✅ Use the correct data type for the value.

```javascript
let age = 25;       // ✅ number
let age = "25";     // ❌ string — wrong type
```

✅ Use `Array.isArray()` to check for arrays.

```javascript
Array.isArray(skills); // true
```

✅ Use `=== null` to check for null.

```javascript
if (manager === null) { }
```

---

## ⚠️ Common Mistakes

### ❌ Treating null as an object

```javascript
let manager = null;
console.log(typeof manager); // "object" ⚠️ misleading
```

> This is expected behaviour — `null` is **not** a real object.

---

### ❌ Treating arrays as non-objects

```javascript
typeof ["C#", ".NET"] // "object" ⚠️
```

✅ Use `Array.isArray()` instead.

## 🌍 Real-world Example

```javascript
const employee = {
    name: "Rahul",
    age: 25,
    isDeveloper: true,
    salary: 50000,
    manager: null,
    phone: undefined,
    skills: ["C#", ".NET", "JavaScript"]
};

console.log(typeof employee.name);       // string
console.log(typeof employee.age);        // number
console.log(typeof employee.isDeveloper);// boolean
console.log(typeof employee.salary);     // number
console.log(typeof employee.manager);    // object
console.log(typeof employee.phone);      // undefined
console.log(typeof employee.skills);     // object
```

## 💡 Interview Definition

> JavaScript has **seven primitive data types**: `string`, `number`, `boolean`, `null`, `undefined`, `symbol`, and `bigint`. Non-primitive types include objects, arrays, and functions. The `typeof` operator is used to check the type of a value. `typeof null` returns `"object"` due to a **historical bug** in JavaScript.
