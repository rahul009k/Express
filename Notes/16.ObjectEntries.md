# 🟦 Object.entries()

---

## 📖 Definition

`Object.entries()` is a built-in JavaScript method that returns an **array of key-value pairs**. Each pair is a two-element array `[key, value]`.

```javascript
Object.entries(object)
```

---

## 💻 Example

```javascript
const laptop = {
    brand: "Dell",
    ram: "16GB",
    storage: "512GB",
    price: 75000
};

console.log(Object.entries(laptop));
```

**Output**

```
[
  [ 'brand', 'Dell' ],
  [ 'ram', '16GB' ],
  [ 'storage', '512GB' ],
  [ 'price', 75000 ]
]
```

---

## 🔄 Looping with Destructuring

```javascript
for (const [key, value] of Object.entries(laptop)) {
    console.log(key, ":", value);
}
```

**Output**

```
brand : Dell
ram : 16GB
storage : 512GB
price : 75000
```

---

## 🔄 Using forEach

```javascript
Object.entries(laptop).forEach(([key, value]) => {
    console.log(key, "->", value);
});
```

**Output**

```
brand -> Dell
ram -> 16GB
storage -> 512GB
price -> 75000
```

---

## 📊 keys() vs values() vs entries()

| Method | Returns |
|--------|---------|
| `Object.keys()` | `['brand', 'ram', 'storage', 'price']` |
| `Object.values()` | `['Dell', '16GB', '512GB', 75000]` |
| `Object.entries()` | `[['brand','Dell'], ['ram','16GB'], ...]` |

---

## ✅ Best Practices

✅ Use `Object.entries()` when you need **both key and value**.

✅ Use destructuring for cleaner code.

```javascript
for (const [key, value] of Object.entries(laptop)) { }
```

---

## ⚠️ Common Mistakes

### ❌ Not destructuring the entry array

```javascript
// Verbose
Object.entries(laptop).forEach(entry => {
    console.log(entry[0], entry[1]);
});

// Cleaner ✅
Object.entries(laptop).forEach(([key, value]) => {
    console.log(key, value);
});
```

---

## 🌍 Real-world Example

```javascript
const user = {
    name: "Rahul",
    email: "rahul@example.com",
    role: "admin",
    age: 26
};

console.log("User Profile:");
Object.entries(user).forEach(([key, value]) => {
    console.log(`  ${key}: ${value}`);
});
```

**Output**

```
User Profile:
  name: Rahul
  email: rahul@example.com
  role: admin
  age: 26
```

## 💡 Interview Definition

> `Object.entries()` is a static method that returns an array of an object's own **enumerable key-value pairs**, where each pair is a two-element array `[key, value]`. It is commonly used with **destructuring** and `for...of` to iterate over both keys and values simultaneously.
