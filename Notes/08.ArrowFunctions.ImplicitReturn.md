# Arrow Functions — Implicit Return

## 📖 Definition

An implicit return means the function returns a value without using the `return` keyword. In arrow functions, when the function body has only a single expression, you can remove the curly braces `{}` and the `return` keyword — JavaScript returns the value automatically.

```javascript
const square = (num) => num * num;
```

---

# Why do we need Implicit Return?

Explicit return (with curly braces) is more verbose.

```javascript
const square = (num) => {
    return num * num;
};
```

Implicit return is shorter and cleaner.

```javascript
const square = (num) => num * num;
```

---

# Syntax

```
const functionName = (parameters) => expression;
```

No curly braces. No `return` keyword. Just the expression.

---

# Examples

## 1. Square a Number

Explicit

```javascript
const square = (num) => {
    return num * num;
};
```

Implicit

```javascript
const square = (num) => num * num;

console.log(square(9));
```

Output

```
81
```

---

## 2. Check Even Number

Explicit

```javascript
const isEven = (num) => {
    return num % 2 === 0;
};
```

Implicit

```javascript
const isEven = (num) => num % 2 === 0;

console.log(isEven(79));
```

Output

```
false
```

---

## 3. Full Name

Explicit

```javascript
const fullName = (first, last) => {
    return first + " " + last;
};
```

Implicit

```javascript
const fullName = (first, last) => first + " " + last;

console.log(fullName("Rahul", "Kumar"));
```

Output

```
Rahul Kumar
```

---

## 4. Divide

Explicit

```javascript
const divide = (a, b) => {
    return a / b;
};
```

Implicit (correct)

```javascript
const divide = (a, b) => a / b;

console.log(divide(81, 9));
```

Output

```
9
```

---

# Common Mistake — Curly Braces Without Return

This is a common mistake. Adding curly braces without `return` makes the function return `undefined`.

Wrong

```javascript
const divide = (a, b) => { a / b };

console.log(divide(81, 9));
```

Output

```
undefined
```

Correct (implicit)

```javascript
const divide = (a, b) => a / b;
```

Correct (explicit)

```javascript
const divide = (a, b) => {
    return a / b;
};
```

---

# When to Use Implicit Return

✅ Use implicit return for simple, single-expression functions.

```javascript
const double = (n) => n * 2;
```

Use explicit return for multi-line logic.

```javascript
const calculate = (price, tax) => {
    const taxAmount = price * tax / 100;
    return price + taxAmount;
};
```

---

# Implicit Return vs Explicit Return

| | Implicit | Explicit |
|--|---------|---------|
| Curly braces | ❌ | ✅ |
| return keyword | ❌ | ✅ |
| Best for | Single expression | Multi-line logic |

---

# Best Practices

✅ Use implicit return for short, readable one-liners.

```javascript
const isAdult = (age) => age >= 18;
```

Avoid implicit return for complex logic — use explicit return instead.

---

# Real-world Example

```javascript
const applyDiscount = (price, discount) => price - (price * discount / 100);

console.log(applyDiscount(500, 10));
```

Output

```
450
```
