# 🟪 Arrow Functions — Implicit Return

---

## 📖 Definition

**Implicit return** means the function returns a value **without** using the `return` keyword. In arrow functions, when the body has only a single expression, you can remove the curly braces `{}` and the `return` keyword — JavaScript returns the value automatically.

```javascript
const square = (num) => num * num;
```

---

## ❓ Why do we need Implicit Return?

Explicit return is more verbose.

```javascript
const square = (num) => {
    return num * num;
};
```

Implicit return is **shorter** and **cleaner**.

```javascript
const square = (num) => num * num;
```

---

## ✍️ Syntax

```
const functionName = (parameters) => expression;
```

> 🚫 No curly braces. 🚫 No `return` keyword. Just the expression.

---

## 💻 Examples

### 1️⃣ Square a Number

```javascript
// Explicit
const square = (num) => {
    return num * num;
};

// Implicit ✅
const square = (num) => num * num;

console.log(square(9));
```

**Output** → `81`

---

### 2️⃣ Check Even Number

```javascript
// Explicit
const isEven = (num) => {
    return num % 2 === 0;
};

// Implicit ✅
const isEven = (num) => num % 2 === 0;

console.log(isEven(79));
```

**Output** → `false`

---

### 3️⃣ Full Name

```javascript
// Explicit
const fullName = (first, last) => {
    return first + " " + last;
};

// Implicit ✅
const fullName = (first, last) => first + " " + last;

console.log(fullName("Rahul", "Kumar"));
```

**Output** → `Rahul Kumar`

---

### 4️⃣ Divide

```javascript
// Explicit
const divide = (a, b) => {
    return a / b;
};

// Implicit ✅
const divide = (a, b) => a / b;

console.log(divide(81, 9));
```

**Output** → `9`

---

## 🐛 Common Mistake — Curly Braces Without Return

> ⚠️ This is the most common mistake with implicit return.

```javascript
const divide = (a, b) => { a / b }; // ❌ returns undefined

console.log(divide(81, 9)); // undefined
```

**Why?** — Curly braces `{}` make JavaScript treat it as a **function body**, not an expression. Without `return`, it returns `undefined`.

✅ Fix — either remove curly braces (implicit):

```javascript
const divide = (a, b) => a / b;
```

✅ Or keep curly braces and add `return` (explicit):

```javascript
const divide = (a, b) => {
    return a / b;
};
```

---

## 📊 Implicit vs Explicit Return

| | Implicit | Explicit |
|--|:-------:|:-------:|
| Curly braces | ❌ | ✅ |
| `return` keyword | ❌ | ✅ |
| Best for | Single expression | Multi-line logic |

---

## ✅ Best Practices

✅ Use implicit return for short, readable one-liners.

```javascript
const isAdult = (age) => age >= 18;
```

❌ Avoid implicit return for complex logic — use explicit return instead.

```javascript
const calculate = (price, tax) => {
    const taxAmount = price * tax / 100;
    return price + taxAmount;
};
```

---

## 🌍 Real-world Example

```javascript
const applyDiscount = (price, discount) => price - (price * discount / 100);

console.log(applyDiscount(500, 10)); // 450
```
