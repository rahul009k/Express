# 🟥 Array.map()

---

## 📖 Definition

`map()` is an array method that creates a **new array** by applying a function to **every element** of the original array. It does **not** modify the original array.

```javascript
array.map(callback)
```

---

## ❓ Why do we need map()?

Without `map()`:

```javascript
const numbers = [5, 10, 15, 20];
const result = [];

for (let i = 0; i < numbers.length; i++) {
    result.push(numbers[i] * 3);
}
```

With `map()` — **one clean line**:

```javascript
const result = numbers.map(n => n * 3);
```

---

## 💻 Example

```javascript
const numbers = [5, 10, 15, 20];

const result = numbers.map(numbers => numbers * 3);

console.log(result);
```

**Output** → `[ 15, 30, 45, 60 ]`

---

## 🔒 Original Array is NOT Modified

```javascript
const numbers = [5, 10, 15, 20];
const result = numbers.map(n => n * 3);

console.log(numbers); // [ 5, 10, 15, 20 ] — unchanged
console.log(result);  // [ 15, 30, 45, 60 ]
```

---

## 💻 More Examples

### 🔢 Double each number

```javascript
const doubled = [1, 2, 3, 4, 5].map(n => n * 2);
console.log(doubled); // [ 2, 4, 6, 8, 10 ]
```

---

### 🔤 Convert to uppercase

```javascript
const names = ["rahul", "amit", "neha"];
const upper = names.map(name => name.toUpperCase());
console.log(upper); // [ 'RAHUL', 'AMIT', 'NEHA' ]
```

---

### 📦 Extract property from objects

```javascript
const users = [
    { name: "Rahul", age: 26 },
    { name: "Amit", age: 24 }
];

const names = users.map(user => user.name);
console.log(names); // [ 'Rahul', 'Amit' ]
```

---

## 📊 map() vs forEach()

| | `map()` | `forEach()` |
|--|:------:|:---------:|
| Returns | New array | `undefined` |
| Original array | Unchanged | Unchanged |
| Use case | Transform data | Side effects |

---

## ✅ Best Practices

✅ Use `map()` when you want to **transform** an array into a new array.

✅ Do not use `map()` just for side effects — use `forEach()` instead.

---

## ⚠️ Common Mistakes

### ❌ Forgetting to return a value

```javascript
const result = numbers.map(n => {
    n * 3; // ❌ no return
});

console.log(result); // [ undefined, undefined, undefined, undefined ]
```

```javascript
const result = numbers.map(n => n * 3); // ✅ implicit return
```

## 🌍 Real-world Example

```javascript
const products = [
    { name: "Laptop", price: 75000 },
    { name: "Mouse", price: 500 },
    { name: "Keyboard", price: 1500 }
];

const discounted = products.map(product => ({
    name: product.name,
    price: product.price * 0.9
}));

console.log(discounted);
```

**Output**

```
[
  { name: 'Laptop', price: 67500 },
  { name: 'Mouse', price: 450 },
  { name: 'Keyboard', price: 1350 }
]
```
