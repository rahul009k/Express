# 🟪 Arrow Functions — Returning Objects

---

## 📖 Definition

When an arrow function needs to **return an object** using implicit return, you must wrap the object in parentheses `()`. Without parentheses, JavaScript treats `{}` as the **function body**, not an object.

```javascript
const createUser = (name, age) => ({
    name: name,
    age: age
});
```

---

## ❓ Why Parentheses?

Without parentheses JavaScript thinks `{}` is the function body.

```javascript
const createUser = (name, age) => {
    name: name,
    age: age
}; // ❌ returns undefined
```

```javascript
const createUser = (name, age) => ({
    name: name,
    age: age
}); // ✅ returns object
```

> 💡 The `()` tells JavaScript — **this is an object, not a function body**.

---

## 💻 Examples

### 1️⃣ Create User

```javascript
// Regular function
const createUser = function(name, age) {
    return { name: name, age: age };
};

// Arrow function ✅
const createUser = (name, age) => ({
    name: name,
    age: age
});

console.log(createUser("Rahul", 26));
```

**Output** → `{ name: 'Rahul', age: 26 }`

---

### 2️⃣ Create Point

```javascript
const createPoint = (x, y) => ({
    x: x,
    y: y
});

console.log(createPoint(8, 9));
```

**Output** → `{ x: 8, y: 9 }`

---

### 3️⃣ Create Product — Shorthand Properties

```javascript
// Verbose
const createProduct = (id, price) => ({
    id: id,
    price: price
});

// Shorthand ✅
const createProduct = (id, price) => ({
    id,
    price
});

console.log(createProduct(1, 100));
```

**Output** → `{ id: 1, price: 100 }`

---

## 🔑 Shorthand Property Names

When the **key name** and **variable name** are the same, you can use shorthand.

```javascript
const name = "Rahul";
const age = 26;

const user = { name, age };       // ✅ shorthand
const user = { name: name, age: age }; // verbose
```

Both produce the same result.

---

## ✍️ Syntax Summary

```
const fn = (params) => ({ key: value });
```

- Outer `()` → tells JS this is an **object**
- Inner `{}` → the actual **object literal**

---

## ✅ Best Practices

✅ Always wrap returned objects in parentheses.

```javascript
const getUser = (name) => ({ name });
```

✅ Use shorthand property names when key and variable match.

```javascript
const createPoint = (x, y) => ({ x, y });
```

---

## ⚠️ Common Mistakes

### ❌ Missing parentheses around object

```javascript
const createUser = (name, age) => {
    name: name,
    age: age
}; // ❌ undefined
```

```javascript
const createUser = (name, age) => ({
    name: name,
    age: age
}); // ✅
```

---

## 🌍 Real-world Example

```javascript
const createOrder = (id, product, amount) => ({
    id,
    product,
    amount,
    status: "pending"
});

console.log(createOrder(101, "Laptop", 75000));
```

**Output**

```
{ id: 101, product: 'Laptop', amount: 75000, status: 'pending' }
```
