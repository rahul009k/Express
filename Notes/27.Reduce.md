# Array.reduce()

## 📖 Definition

`reduce()` is an array method that reduces an array to a **single value** by applying a callback function to each element, accumulating the result as it goes.

```javascript
array.reduce((accumulator, currentValue) => expression, initialValue)
```

---

# Why do we need reduce()?

When you want to combine all elements of an array into one value — like a total, a product, or a combined object.

Without `reduce()`

```javascript
const prices = [100, 200, 300, 400];
let total = 0;

for (let i = 0; i < prices.length; i++) {
    total += prices[i];
}
```

With `reduce()`

```javascript
const total = prices.reduce((sum, amount) => sum + amount, 0);
```

---

# Syntax

```javascript
array.reduce((accumulator, currentValue) => {
    return updatedAccumulator;
}, initialValue);
```

| Parameter | Description |
|-----------|-------------|
| `accumulator` | The running total / accumulated result |
| `currentValue` | The current element being processed |
| `initialValue` | The starting value of the accumulator |

---

# Example

```javascript
const prices = [100, 200, 300, 400];

const total = prices.reduce((sum, amount) => sum + amount, 0);

console.log(total);
```

Output

```
1000
```

---

# How it Works Step by Step

```
Initial value: 0

Step 1: sum = 0 + 100 = 100
Step 2: sum = 100 + 200 = 300
Step 3: sum = 300 + 300 = 600
Step 4: sum = 600 + 400 = 1000

Result: 1000
```

# Finding Maximum Value

```javascript
const numbers = [5, 12, 3, 8, 20, 1];

const max = numbers.reduce((highest, num) => num > highest ? num : highest, 0);

console.log(max);
```

Output

```
20
```

---

# Counting Occurrences

```javascript
const fruits = ["Apple", "Banana", "Apple", "Mango", "Banana", "Apple"];

const count = fruits.reduce((acc, fruit) => {
    acc[fruit] = (acc[fruit] || 0) + 1;
    return acc;
}, {});

console.log(count);
```

Output

```
{ Apple: 3, Banana: 2, Mango: 1 }
```

---

# Flattening an Array

```javascript
const nested = [[1, 2], [3, 4], [5, 6]];

const flat = nested.reduce((acc, arr) => acc.concat(arr), []);

console.log(flat);
```

Output

```
[ 1, 2, 3, 4, 5, 6 ]
```

---

# reduce() vs Other Methods

| Method | Returns | Use case |
|--------|---------|---------|
| `map()` | New array (same length) | Transform elements |
| `filter()` | New array (shorter) | Select elements |
| `reduce()` | Single value | Combine / accumulate |

---

# Best Practices

✅ Always provide an initial value.

```javascript
prices.reduce((sum, amount) => sum + amount, 0);
```

Without an initial value, the first element is used as the accumulator — this can cause bugs on empty arrays.

Use meaningful names for accumulator and current value.

```javascript
prices.reduce((total, price) => total + price, 0);
```

---

# Common Mistakes

## Forgetting the initial value

```javascript
const prices = [];

const total = prices.reduce((sum, amount) => sum + amount);
```

Output

```
TypeError: Reduce of empty array with no initial value
```

Correct

```javascript
const total = prices.reduce((sum, amount) => sum + amount, 0);
```

---

## Forgetting to return the accumulator

Wrong

```javascript
const total = prices.reduce((sum, amount) => {
    sum + amount;
}, 0);
```

Output

```
undefined
```

Correct

```javascript
const total = prices.reduce((sum, amount) => {
    return sum + amount;
}, 0);
```

# Real-world Example

```javascript
const cart = [
    { name: "Laptop", price: 75000 },
    { name: "Mouse", price: 500 },
    { name: "Keyboard", price: 1500 }
];

const total = cart.reduce((sum, item) => sum + item.price, 0);

console.log("Cart Total: ₹" + total);
```

Output

```
Cart Total: ₹77000
```
