# 🟦 Variables — Multiple Declarations

---

## 📖 Definition

Variables are **named containers** that store data values. JavaScript allows you to declare multiple variables and reassign them as needed. A variable declared but not assigned holds `undefined` by default.

---

## ❓ Why do we need Variables?

Variables let you store, reuse, and update data throughout your program without repeating values.

```javascript
const name = "Rahul";

console.log(name);
console.log(name);
console.log(name);
```

**Output**

```
Rahul
Rahul
Rahul
```

---

## ✍️ Declaring Multiple Variables

```javascript
const name = "Rahul";

let age = 25;

const country = "India";

let experience = 1;
```

---

## 🔄 Reassigning Variables

`let` variables can be updated at any time.

```javascript
let age = 25;
age = 26;

let experience = 1;
experience = 2;

console.log(age);
console.log(experience);
```

**Output**

```
26
2
```

---

## ❓ Uninitialized Variable

A variable declared without a value is `undefined`.

```javascript
let email;

console.log(email);
```

**Output**

```
undefined
```

---

## 💻 Full Code Example

```javascript
const name = "Rahul";
let age = 25;
const country = "India";
let experience = 1;

age = 26;
experience = 2;

let email;

console.log(email);
console.log(name);
console.log(age);
console.log(country);
console.log(experience);
```

**Output**

```
undefined
Rahul
26
India
2
```

---

## 🔒 const vs let

```javascript
const country = "India";

country = "USA"; // ❌ TypeError
```

**Output**

```
TypeError: Assignment to constant variable.
```

> ⚠️ `const` values cannot be changed after assignment.

---

## 📊 var vs let vs const

| Keyword | Reassign | Redeclare | Scope |
|---------|:--------:|:---------:|-------|
| `var` | ✅ | ✅ | Function |
| `let` | ✅ | ❌ | Block |
| `const` | ❌ | ❌ | Block |

---

## ✅ Best Practices

✅ Use `const` for values that never change.

```javascript
const country = "India";
```

✅ Use `let` for values that will be updated.

```javascript
let experience = 1;
experience = 2;
```

✅ Always initialize variables when possible.

```javascript
let email = "";
```

❌ Instead of leaving it undefined.

---

## ⚠️ Common Mistakes

### ❌ Accessing property of undefined

```javascript
let email;
console.log(email.length); // ❌ TypeError
```

```javascript
let email = "";
console.log(email.length); // ✅ 0
```

---

### ❌ Reassigning a const

```javascript
const country = "India";
country = "USA"; // ❌ TypeError
```

```javascript
let country = "India";
country = "USA"; // ✅ Works
```

## 🌍 Real-world Example

```javascript
const userName = "Rahul";

let email;

experience = 3;
email = "rahul@example.com";

```
