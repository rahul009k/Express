# Object.values()

## 📖 Definition

`Object.values()` is a built-in JavaScript method that returns an array of all the property values of an object.

```javascript
Object.values(object)
```

It gives you only the values, not the keys.

---

# Why do we need Object.values()?

When you want to work with the data stored in an object without caring about the property names.

---

# Syntax

```javascript
Object.values(objectName)
```

Returns an array of the object's values.

---

# Example

```javascript
const laptop = {
    brand: "Dell",
    ram: "16GB",
    storage: "512GB",
    price: 75000
};

console.log(Object.values(laptop));
```

Output

```
[ 'Dell', '16GB', '512GB', 75000 ]
```

---

# What it Returns

`Object.values()` returns an array of the actual values.

```javascript
const values = Object.values(laptop);

console.log(values);
console.log(values.length);
console.log(values[0]);
```

Output

```
[ 'Dell', '16GB', '512GB', 75000 ]
4
Dell
```

---

# Looping Over Values

```javascript
const values = Object.values(laptop);

for (const value of values) {
    console.log(value);
}
```

Output

```
Dell
16GB
512GB
75000
```

---

# Summing Numeric Values

```javascript
const scores = {
    math: 90,
    science: 85,
    english: 78
};

const total = Object.values(scores).reduce((sum, val) => sum + val, 0);

console.log(total);
```

Output

```
253
```

---

# Object.keys() vs Object.values() vs Object.entries()

| Method | Returns |
|--------|---------|
| `Object.keys()` | Array of keys |
| `Object.values()` | Array of values |
| `Object.entries()` | Array of [key, value] pairs |

---

# Best Practices

✅ Use `Object.values()` when you only need the data, not the property names.

```javascript
const values = Object.values(laptop);
```

Use with `reduce()` to calculate totals from object values.

```javascript
Object.values(scores).reduce((sum, val) => sum + val, 0);
```

---

# Common Mistakes

## Expecting keys instead of values

`Object.values()` returns values only.

```javascript
console.log(Object.values(laptop));
```

Output

```
[ 'Dell', '16GB', '512GB', 75000 ]
```

Use `Object.keys()` if you need the keys.

---

## Modifying values through the returned array

The returned array is a copy. Modifying it does not change the original object.

```javascript
const values = Object.values(laptop);

values[0] = "HP";

console.log(laptop.brand);
```

Output

```
Dell
```

# Real-world Example

```javascript
const product = {
    name: "Laptop",
    brand: "Dell",
    ram: "16GB",
    price: 75000
};

console.log("Product details:");

Object.values(product).forEach(value => console.log("-", value));
```

Output

```
Product details:
- Laptop
- Dell
- 16GB
- 75000
```

# Interview Definition

> `Object.values()` is a static method that returns an array of an object's own enumerable property values. It does not include keys or inherited properties. The returned array can be iterated, summed, or processed like any other array.
