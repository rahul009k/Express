# 🟦 Object Values

---

## 📖 Definition

Object.values() returns the values stored in an object.

---

## ❓ Why it was introduced

It is useful when we need the data without the keys.

---

## ✍️ Syntax

```javascript
Object.values(user);
```

---

## 💻 Code Example

```javascript
const user = { name: "Rahul", age: 25 };
console.log(Object.values(user));
```

---

## 🧩 Line-by-line Explanation

- Object.values() returns the values in order.
