# Object.keys()

## 📖 Definition

`Object.keys()` is a built-in JavaScript method that returns an array of all the property names (keys) of an object.

```javascript
Object.keys(object)
```

It gives you only the keys, not the values.

---

# Why do we need Object.keys()?

When you want to know what properties an object has, or when you want to loop over the keys of an object.

---

# Syntax

```javascript
Object.keys(objectName)
```

Returns an array of strings (the property names).

---

# Example

```javascript
const laptop = {
    brand: "Dell",
    ram: "16GB",
    storage: "512GB",
    price: 75000
};

console.log(Object.keys(laptop));
```

Output

```
[ 'brand', 'ram', 'storage', 'price' ]
```

---

# What it Returns

`Object.keys()` returns an array of strings.

```javascript
const keys = Object.keys(laptop);

console.log(keys);
console.log(keys.length);
console.log(keys[0]);
```

Output

```
[ 'brand', 'ram', 'storage', 'price' ]
4
brand
```

---

# Looping Over Keys

```javascript
const keys = Object.keys(laptop);

for (const key of keys) {
    console.log(key);
}
```

Output

```
brand
ram
storage
price
```

---

# Counting Properties

```javascript
console.log(Object.keys(laptop).length);
```

Output

```
4
```

---

# Object.keys() vs Object.values() vs Object.entries()

| Method | Returns |
|--------|---------|
| `Object.keys()` | Array of keys |
| `Object.values()` | Array of values |
| `Object.entries()` | Array of [key, value] pairs |

---

# Best Practices

✅ Use `Object.keys()` when you only need the property names.

```javascript
const keys = Object.keys(laptop);
```

Use `.length` to count the number of properties.

```javascript
Object.keys(laptop).length
```

Combine with `forEach` or `for...of` to iterate.

```javascript
Object.keys(laptop).forEach(key => console.log(key));
```

---

# Common Mistakes

## Calling on a non-object

Wrong

```javascript
Object.keys("hello");
```

This returns the indices of the string characters, not what you expect.

Correct

```javascript
Object.keys({ name: "Rahul" });
```

---

## Expecting values instead of keys

`Object.keys()` returns only keys.

```javascript
console.log(Object.keys(laptop));
```

Output

```
[ 'brand', 'ram', 'storage', 'price' ]
```

Use `Object.values()` if you need the values.

---

# Real-world Example

```javascript
const user = {
    name: "Rahul",
    email: "rahul@example.com",
    role: "admin",
    age: 26
};

const fields = Object.keys(user);

console.log("User has", fields.length, "fields:");

fields.forEach(field => console.log("-", field));
```

Output

```
User has 4 fields:
- name
- email
- role
- age
```

# Interview Definition

> `Object.keys()` is a static method that returns an array of an object's own enumerable property names (keys). It does not include inherited properties. The result is an array of strings that can be iterated, counted, or used to access values dynamically.
