# 🟦 Object.keys()

---

## 📖 Definition

`Object.keys()` is a built-in JavaScript method that returns an **array of all the property names (keys)** of an object.

```javascript
Object.keys(object)
```

> 💡 It gives you only the **keys**, not the values.

---

## 💻 Example

```javascript
const laptop = {
    brand: "Dell",
    ram: "16GB",
    storage: "512GB",
    price: 75000
};

console.log(Object.keys(laptop));
```

**Output**

```
[ 'brand', 'ram', 'storage', 'price' ]
```

---

## 🔢 What it Returns

```javascript
const keys = Object.keys(laptop);

console.log(keys);         // [ 'brand', 'ram', 'storage', 'price' ]
console.log(keys.length);  // 4
console.log(keys[0]);      // brand
```

---

## 🔄 Looping Over Keys

```javascript
for (const key of Object.keys(laptop)) {
    console.log(key);
}
```

**Output**

```
brand
ram
storage
price
```

---

## 🔢 Counting Properties

```javascript
console.log(Object.keys(laptop).length); // 4
```

---

## 📊 keys() vs values() vs entries()

| Method | Returns |
|--------|---------|
| `Object.keys()` | `['brand', 'ram', 'storage', 'price']` |
| `Object.values()` | `['Dell', '16GB', '512GB', 75000]` |
| `Object.entries()` | `[['brand','Dell'], ['ram','16GB'], ...]` |

---

## ✅ Best Practices

✅ Use `Object.keys()` when you only need the property names.

✅ Use `.length` to count the number of properties.

```javascript
Object.keys(laptop).length
```

✅ Combine with `forEach` or `for...of` to iterate.

```javascript
Object.keys(laptop).forEach(key => console.log(key));
```

---

## ⚠️ Common Mistakes

### ❌ Expecting values instead of keys

```javascript
console.log(Object.keys(laptop));
// [ 'brand', 'ram', 'storage', 'price' ] — keys only
```

Use `Object.values()` if you need the values.

---

## 🌍 Real-world Example

```javascript
const user = {
    name: "Rahul",
    email: "rahul@example.com",
    role: "admin",
    age: 26
};

const fields = Object.keys(user);

console.log("User has", fields.length, "fields:");
fields.forEach(field => console.log("-", field));
```

**Output**

```
User has 4 fields:
- name
- email
- role
- age
```

## 💡 Interview Definition

> `Object.keys()` is a static method that returns an array of an object's own **enumerable property names** (keys). It does **not** include inherited properties. The result is an array of strings that can be iterated, counted, or used to access values dynamically.
