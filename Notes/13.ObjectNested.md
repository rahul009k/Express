# 🟦 Nested Objects

---

## 📖 Definition

Nested objects contain objects inside other objects.

---

## ❓ Why it was introduced

They are useful for representing structured data.

---

## ✍️ Syntax

```javascript
const user = { profile: { name: "Rahul" } };
```

---

## 💻 Code Example

```javascript
const user = { profile: { name: "Rahul" } };
console.log(user.profile.name);
```

---

## 🧩 Line-by-line Explanation

- The inner object is accessed through the outer property.
