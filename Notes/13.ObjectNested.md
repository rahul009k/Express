# Nested Objects

## 📖 Definition

A nested object is an object that contains another object as a property value. This allows you to represent complex, hierarchical data structures.

```javascript
const company = {
    name: "OpenAI",
    location: {
        city: "San Francisco",
        country: "USA"
    }
};
```

---

# Why do we need Nested Objects?

Real-world data is often hierarchical. A company has a location, a location has a city and country. Nesting objects mirrors this structure naturally.

Without nesting

```javascript
const companyName = "OpenAI";
const companyCity = "San Francisco";
const companyCountry = "USA";
```

With nesting

```javascript
const company = {
    name: "OpenAI",
    location: {
        city: "San Francisco",
        country: "USA"
    }
};
```

---

# Accessing Nested Properties

## Dot Notation

```javascript
console.log(company.name);

console.log(company.location.city);

console.log(company.location.country);
```

Output

```
OpenAI
San Francisco
USA
```

---

## Bracket Notation

```javascript
console.log(company["ceo"]["name"]);
```

Output

```
Sam
```

---

## Mixed Notation

```javascript
console.log(company.ceo["age"]);
```

Output

```
40
```

---

# Full Example

```javascript
const company = {
    name: "OpenAI",
    location: {
        city: "San Francisco",
        country: "USA"
    },
    ceo: {
        name: "Sam",
        age: 40
    }
};

console.log(company.name);
console.log(company.location.city);
console.log(company.location.country);
console.log(company["ceo"]["name"]);
console.log(company.ceo["age"]);
console.log(company);
```

Output

```
OpenAI
San Francisco
USA
Sam
40
{
  name: 'OpenAI',
  location: { city: 'San Francisco', country: 'USA' },
  ceo: { name: 'Sam', age: 40 }
}
```

# Deeply Nested Objects

```javascript
const school = {
    name: "ABC School",
    address: {
        city: "Delhi",
        pincode: {
            code: 110001
        }
    }
};

console.log(school.address.pincode.code);
```

Output

```
110001
```

---

# Updating Nested Properties

```javascript
company.location.city = "New York";

console.log(company.location.city);
```

Output

```
New York
```

---

# Best Practices

✅ Use dot notation for known, fixed keys.

```javascript
company.location.city
```

Use bracket notation for dynamic keys.

```javascript
company["location"]["city"]
```

Avoid deeply nesting more than 3 levels — it becomes hard to read.

Use optional chaining `?.` to safely access nested properties.

```javascript
console.log(company?.ceo?.name);
```

---

# Common Mistakes

## Accessing a non-existent nested property

```javascript
console.log(company.founder.name);
```

Output

```
TypeError: Cannot read properties of undefined
```

Safe access using optional chaining

```javascript
console.log(company?.founder?.name);
```

Output

```
undefined
```

# Real-world Example

```javascript
const order = {
    id: 1001,
    customer: {
        name: "Rahul",
        email: "rahul@example.com"
    },
    product: {
        name: "Laptop",
        price: 75000
    },
    status: "shipped"
};

console.log(order.customer.name);
console.log(order.product.name);
console.log(order.product.price);
console.log(order.status);
```

Output

```
Rahul
Laptop
75000
shipped
```

# Interview Definition

Optional chaining (`?.`) is used to safely access deeply nested properties without throwing an error if an intermediate property is `undefined`.
