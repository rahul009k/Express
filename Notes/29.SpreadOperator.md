# Spread Operator

## 📖 Definition

The spread operator `...` in JavaScript allows you to expand iterable values like arrays or object properties into a new array or object.

---

# Why use the spread operator?

It helps you create copies or merge values without mutating the original array or object.

---

# Spread with arrays

## Merge arrays

```javascript
const fruits = ["Apple", "Banana"];
const vegetables = ["Carrot", "Potato"];
const food = [...fruits, ...vegetables];
console.log(food);
```

Output

```
[ 'Apple', 'Banana', 'Carrot', 'Potato' ]
```

## Add values to an array

```javascript
const numbers = [1, 2, 3];
const newNumbers = [...numbers, 4, 5];
console.log(newNumbers);
```

Output

```
[ 1, 2, 3, 4, 5 ]
```

## Copy an array

```javascript
const original = [10, 20, 30];
const copy = [...original];
console.log(copy);
```

Output

```
[ 10, 20, 30 ]
```

---

# Spread with objects

## Copy object properties

```javascript
const person = {
    name: "Rahul",
    age: 24
};
const personCopy = { ...person };
console.log(personCopy);
```

Output

```
{ name: 'Rahul', age: 24 }
```

## Update object properties immutably

```javascript
const student = {
    name: "Rahul",
    age: 24,
    city: "Hyderabad"
};

const updatedStudent = {
    ...student,
    city: "Bangalore"
};
console.log(updatedStudent);
```

Output

```
{ name: 'Rahul', age: 24, city: 'Bangalore' }
```

---

# Combine object and array updates

To update nested values without changing the original data, spread both the object and the nested array.

```javascript
const user = {
    name: "Rahul",
    age: 24,
    skills: ["HTML", "CSS", "JavaScript"]
};

const updatedSkills = [...user.skills, "Express"];
const updatedUser = {
    ...user,
    age: 25,
    skills: updatedSkills
};

console.log(updatedUser);
```

Output

```
{
  name: 'Rahul',
  age: 25,
  skills: [ 'HTML', 'CSS', 'JavaScript', 'Express' ]
}
```

---

# Notes

- Spread copies elements or properties by value for arrays and objects.
- For nested objects or arrays, you may still need deeper copying if you want to avoid mutation of nested data.
- Use spread to keep data immutable and avoid modifying the original source.
