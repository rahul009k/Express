# 🟥 Arrays

---

## 📖 Definition

An **array** is an ordered collection of values stored in a single variable. Each value is called an **element**, and each element has an **index** starting from `0`.

```javascript
const colors = ['red', 'green', 'blue', 'black'];
```

---

## ❓ Why do we need Arrays?

Without arrays you would need separate variables for each value.

```javascript
let color1 = "red";
let color2 = "green";
let color3 = "blue";
```

With an array you store them all in **one place**.

```javascript
const colors = ['red', 'green', 'blue'];
```

---

## 🔢 Accessing Elements by Index

> ⚠️ Index starts at `0`.

```javascript
const colors = ['red', 'green', 'blue', 'black'];

console.log(colors[0]); // red
console.log(colors[3]); // black
```

---

## 🔄 Updating Elements

```javascript
const numbers = [10, 20, 30, 40];

numbers[1] = 25;
numbers[3] = 45;

console.log(numbers[1]); // 25
console.log(numbers[3]); // 45
```

---

## 🟢 push() — Add to End

```javascript
const cities = ["Delhi", "Mumbai"];

cities.push("Bangalore");
cities.push("Chennai");

console.log(cities);
```

**Output** → `[ 'Delhi', 'Mumbai', 'Bangalore', 'Chennai' ]`

---

## 🔴 pop() — Remove from End

```javascript
const animals = ["Dog", "Cat", "Tiger", "Lion"];

const removedAnimal = animals.pop();

console.log(removedAnimal); // Lion
console.log(animals);       // [ 'Dog', 'Cat', 'Tiger' ]
```

---

## 🔴 shift() — Remove from Beginning

```javascript
const books = ["Java", "C#", "Python", "JavaScript"];

const removedBook = books.shift();

console.log(removedBook); // Java
console.log(books);       // [ 'C#', 'Python', 'JavaScript' ]
```

---

## 🟢 unshift() — Add to Beginning

```javascript
const cars = ["BMW", "Audi"];

cars.unshift("Toyota", "Tesla");

console.log(cars);
```

**Output** → `[ 'Toyota', 'Tesla', 'BMW', 'Audi' ]`

---

## 🔢 length — Number of Elements

```javascript
const languages = ["Java", "C#", "Python", "JavaScript", "Go"];

console.log(languages.length);                    // 5
console.log(languages[languages.length - 1]);     // Go
```

---

## 📊 Array Methods Summary

| Method | Description | Mutates? |
|--------|-------------|:-------:|
| `push()` | ➕ Add to end | ✅ |
| `pop()` | ➖ Remove from end | ✅ |
| `shift()` | ➖ Remove from beginning | ✅ |
| `unshift()` | ➕ Add to beginning | ✅ |
| `length` | 🔢 Number of elements | — |

---

## ✅ Best Practices

✅ Use `const` for arrays — you can still modify elements.

```javascript
const colors = ["Red", "Green"];
colors.push("Blue"); // ✅ works fine
```

✅ Use meaningful array names (plural).

```javascript
const users = [];
const products = [];
```

✅ Use `length - 1` to access the last element.

---

## ⚠️ Common Mistakes

### ❌ Accessing out-of-bounds index

```javascript
const colors = ["Red", "Green", "Blue"];
console.log(colors[5]); // undefined — no error
```

---

### ❌ Confusing push and unshift

- `push()` → adds to the **end**
- `unshift()` → adds to the **beginning**

---

## 🌍 Real-world Example

```javascript
const cart = [];

cart.push("Laptop");
cart.push("Mouse");
cart.push("Keyboard");

console.log("Cart:", cart);
console.log("Items:", cart.length);

cart.pop();

console.log("After removing last item:", cart);
```

**Output**

```
Cart: [ 'Laptop', 'Mouse', 'Keyboard' ]
Items: 3
After removing last item: [ 'Laptop', 'Mouse' ]
```
