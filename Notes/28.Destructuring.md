# Destructuring

## 📖 Definition

Destructuring is a JavaScript syntax that allows you to unpack values from arrays or properties from objects into individual variables in a single, clean statement.

```javascript
const [city1, city2, city3] = cities;
```

Instead of

```javascript
const city1 = cities[0];
const city2 = cities[1];
const city3 = cities[2];
```

---

# Why do we need Destructuring?

Without destructuring you access elements one by one.

```javascript
const cities = ["Delhi", "Mumbai", "Bangalore"];

const city1 = cities[0];
const city2 = cities[1];
const city3 = cities[2];
```

With destructuring it is done in one line.

```javascript
const [city1, city2, city3] = cities;
```

---

# Array Destructuring

## Basic

```javascript
const cities = ["Delhi", "Mumbai", "Bangalore"];

const [city1, city2, city3] = cities;

console.log(city1);
console.log(city2);
console.log(city3);
```

Output

```
Delhi
Mumbai
Bangalore
```

---

## Trick 1 — Skip Values

Use a comma `,` to skip elements you don't need.

```javascript
const colors = ["Red", "Green", "Blue", "Black"];

const [firstColor, , , lastColor] = colors;

console.log(firstColor);
console.log(lastColor);
```

Output

```
Red
Black
```

---

## Trick 2 — Rest Operator (...)

Use `...` to collect the remaining elements into a new array.

```javascript
const subjects = ["Math", "Science", "English", "History"];

const [firstSubject, ...otherSubjects] = subjects;

console.log(firstSubject);
console.log(otherSubjects);
```

Output

```
Math
[ 'Science', 'English', 'History' ]
```

---

# Object Destructuring

Extract properties from an object into variables.

```javascript
const user = {
    name: "Rahul",
    age: 26,
    city: "Delhi"
};

const { name, age, city } = user;

console.log(name);
console.log(age);
console.log(city);
```

Output

```
Rahul
26
Delhi
```

---

# Object Destructuring with Rename

```javascript
const user = { name: "Rahul", age: 26 };

const { name: userName, age: userAge } = user;

console.log(userName);
console.log(userAge);
```

Output

```
Rahul
26
```

---

# Object Destructuring with Default Values

```javascript
const user = { name: "Rahul" };

const { name, role = "user" } = user;

console.log(name);
console.log(role);
```

Output

```
Rahul
user
```

---

# Destructuring in Function Parameters

```javascript
function printUser({ name, age }) {
    console.log(name, age);
}

printUser({ name: "Rahul", age: 26 });
```

Output

```
Rahul 26
```

---

# Nested Destructuring

```javascript
const company = {
    name: "OpenAI",
    location: {
        city: "San Francisco"
    }
};

const { name, location: { city } } = company;

console.log(name);
console.log(city);
```

Output

```
OpenAI
San Francisco
```

# Array vs Object Destructuring

| | Array | Object |
|--|-------|--------|
| Syntax | `[a, b]` | `{ a, b }` |
| Order matters | ✅ | ❌ |
| Rename | Using new variable name | Using `:` |
| Skip elements | Using `,` | Not needed |
| Rest | `...rest` | `...rest` |

---

# Best Practices

✅ Use destructuring to make code cleaner and more readable.

```javascript
const { name, age } = user;
```

Instead of

```javascript
const name = user.name;
const age = user.age;
```

Use default values to avoid `undefined`.

```javascript
const { role = "user" } = user;
```

Use rest operator to collect remaining items.

```javascript
const [first, ...rest] = array;
```

---

# Common Mistakes

## Wrong order in array destructuring

```javascript
const [a, b] = [1, 2, 3];
```

`a = 1`, `b = 2`. Order matters in arrays.

---

## Trying to skip in object destructuring

Object destructuring does not depend on order, so skipping is not needed.

```javascript
const { name, city } = user;
```

You can pick any properties you want.

---

## Forgetting rest must be last

Wrong

```javascript
const [...rest, last] = array;
```

Output

```
SyntaxError
```

Correct

```javascript
const [first, ...rest] = array;
```

# Real-world Example

```javascript
const order = {
    id: 1001,
    customer: "Rahul",
    items: ["Laptop", "Mouse", "Keyboard"],
    total: 77000
};

const { id, customer, items: [firstItem, ...otherItems], total } = order;

console.log(id);
console.log(customer);
console.log(firstItem);
console.log(otherItems);
console.log(total);
```

Output

```
1001
Rahul
Laptop
[ 'Mouse', 'Keyboard' ]
77000
```

Array destructuring is order-based, while object destructuring is name-based. The rest operator `...` can be used to collect remaining elements. Destructuring improves code readability and reduces repetition.
