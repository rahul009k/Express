# Hello World

## 📖 Definition

`console.log()` is a built-in JavaScript function used to print output to the console. It is the first thing you learn in any programming language — printing a message to the screen.

Think of it as telling JavaScript to speak out loud.

```
console.log("Hello Rahul!")  →  Hello Rahul!
```

---

# Why do we need console.log()?

When you write code, you cannot see what is happening inside the program. `console.log()` lets you inspect values, test your code, and understand what is going on.

---

# Basic Syntax

```javascript
console.log("Hello Rahul!");
```

Output

```
Hello Rahul!
```

---

# Printing Multiple Messages

```javascript
console.log("Hello Rahul!");

console.log("Welcome to JavaScript.");

console.log("Let's learn Express.js.");
```

Output

```
Hello Rahul!
Welcome to JavaScript.
Let's learn Express.js.
```

---

# Printing Numbers

```javascript
console.log(100);
```

Output

```
100
```

---

# Printing Variables

```javascript
let name = "Rahul";

console.log(name);
```

Output

```
Rahul
```

---

# Printing Expressions

```javascript
console.log(5 + 10);
```

Output

```
15
```

---

# Printing Multiple Values

```javascript
let name = "Rahul";

let age = 24;

console.log(name, age);
```

Output

```
Rahul 24
```

---

# String Concatenation in console.log

```javascript
let name = "Rahul";

console.log("Hello, " + name + "!");
```

Output

```
Hello, Rahul!
```

---

# Template Literals

```javascript
let name = "Rahul";

console.log(`Hello, ${name}!`);
```

Output

```
Hello, Rahul!
```

---

# Best Practices

✅ Use `console.log()` to debug and test your code.

```javascript
console.log("Checking value:", someVariable);
```

Remove `console.log()` statements before pushing to production.

Use meaningful messages so you know what you are logging.

```javascript
console.log("User name:", name);
```

Instead of

```javascript
console.log(name);
```

---

# Common Mistakes

## Forgetting quotes around strings

Wrong

```javascript
console.log(Hello);
```

Correct

```javascript
console.log("Hello");
```

---

## Misspelling console.log

Wrong

```javascript
Console.log("Hello");

consol.log("Hello");
```

Correct

```javascript
console.log("Hello");
```
