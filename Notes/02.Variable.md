# Variable

## 📖 Definition

A variable is a named container used to store a single value in memory. You declare it, assign a value, and can reassign it later if needed.

```javascript
let age = 25;
```

Here `age` is the variable name and `25` is the value stored in it.

---

# Why do we need Variables?

Without variables you would have to repeat values everywhere.

```javascript
console.log(25);
console.log(25);
console.log(25);
```

With a variable you store it once and reuse it.

```javascript
let age = 25;

console.log(age);
```

---

# Declaring and Assigning

```javascript
let age = 25;

console.log(age);
```

Output

```
25
```

---

# Reassigning a Variable

`let` allows you to change the value after declaration.

```javascript
let age = 25;

age = 26;

console.log(age);
```

Output

```
26
```

---

# const Cannot Be Reassigned

```javascript
const name = "Rahul";

name = "John";
```

Output

```
TypeError: Assignment to constant variable.
```

> This will throw an error because `name` is a constant and cannot be reassigned.

---

# Declaring Without a Value

```javascript
let totalRequests = 0;
```

You can declare a variable and assign it a value later.

```javascript
let totalRequests;

totalRequests = 0;
```

---

# From the Code

```javascript
let age = 25;

age = 26;

console.log(age);

const name = "Rahul";

console.log(name);

let totalRequests = 0;
```

Output

```
26
Rahul
```

# var vs let vs const

| Keyword | Reassign | Redeclare | Scope |
|---------|----------|-----------|-------|
| var | ✅ | ✅ | Function |
| let | ✅ | ❌ | Block |
| const | ❌ | ❌ | Block |

---

# Best Practices

✅ Use `const` by default.

```javascript
const name = "Rahul";
```

Use `let` only when the value needs to change.

```javascript
let age = 25;

age = 26;
```

Avoid `var` in modern JavaScript.

---

# Common Mistakes

## Reassigning a const

Wrong

```javascript
const name = "Rahul";

name = "Amit";
```

Correct

```javascript
let name = "Rahul";

name = "Amit";
```

---

## Using a variable before declaring it

Wrong

```javascript
console.log(score);

let score = 10;
```

Correct

```javascript
let score = 10;

console.log(score);
```

---

# Real-world Example

```javascript
const appName = "MyApp";

let activeUsers = 100;

activeUsers = 105;

console.log(appName);

console.log(activeUsers);
```
