# Object CRUD

## 📖 Definition

CRUD stands for Create, Read, Update, and Delete. These are the four basic operations you can perform on object properties in JavaScript.

```
CRUD
│
├── Create  → Add a new property
├── Read    → Access a property
├── Update  → Change a property value
└── Delete  → Remove a property
```

---

# Why do we need Object CRUD?

Objects are dynamic in JavaScript. You can add, change, or remove properties at any time after the object is created.

---

# Starting Object

```javascript
const employee = {
    id: 1,
    name: "Rahul",
    salary: 50000
};
```

---

# Update — Change an Existing Property

```javascript
employee.salary = 60000;
```

The salary is now updated from 50000 to 60000.

---

# Create — Add a New Property

```javascript
employee.department = "IT";

employee.experience = 3;
```

New properties `department` and `experience` are added to the object.

---

# Delete — Remove a Property

```javascript
delete employee.id;
```

The `id` property is removed from the object.

---

# Read — Print the Object

```javascript
console.log(employee);
```

Output

```
{ name: 'Rahul', salary: 60000, department: 'IT', experience: 3 }
```

> `id` is gone because we deleted it.

---

# Full Example

```javascript
const employee = {
    id: 1,
    name: "Rahul",
    salary: 50000
};

// Update
employee.salary = 60000;

// Create
employee.department = "IT";
employee.experience = 3;

// Delete
delete employee.id;

// Read
console.log(employee);
```

Output

```
{ name: 'Rahul', salary: 60000, department: 'IT', experience: 3 }
```

---

# CRUD Summary

| Operation | Syntax | Example |
|-----------|--------|---------|
| Create | `obj.key = value` | `employee.department = "IT"` |
| Read | `obj.key` | `employee.name` |
| Update | `obj.key = newValue` | `employee.salary = 60000` |
| Delete | `delete obj.key` | `delete employee.id` |

---

# Checking if a Property Exists

```javascript
console.log("name" in employee);
```

Output

```
true
```

```javascript
console.log("id" in employee);
```

Output

```
false
```

# Best Practices

✅ Use `const` for objects — you can still modify properties.

```javascript
const employee = { name: "Rahul" };

employee.salary = 50000;
```

Use `delete` carefully — it permanently removes the property.

Use `null` to clear a value without removing the property.

```javascript
employee.salary = null;
```

---

# Common Mistakes

## Thinking const prevents property changes

Wrong assumption

```javascript
const employee = { name: "Rahul" };

employee.name = "Amit";
```

This works fine. `const` only prevents reassigning the variable, not modifying the object.

---

## Forgetting delete returns true

```javascript
console.log(delete employee.id);
```

Output

```
true
```

`delete` returns `true` even if the property did not exist.

# Real-world Example

```javascript
const user = {
    id: 1,
    name: "Rahul",
    email: "rahul@example.com",
    role: "user"
};

// Update role
user.role = "admin";

// Add new property
user.lastLogin = "2024-01-01";

// Delete sensitive data
delete user.email;

console.log(user);
```

Output

```
{ id: 1, name: 'Rahul', role: 'admin', lastLogin: '2024-01-01' }
```
