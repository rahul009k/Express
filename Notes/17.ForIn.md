# 🟦 for...in Loop

---

## 📖 Definition

The `for...in` loop is used to **iterate over the keys** (property names) of an object. On each iteration, the loop variable holds the current **key as a string**.

```javascript
for (const key in object) {
    // code
}
```

---

## 💻 Example

```javascript
const laptop = {
    brand: "Dell",
    ram: "16GB",
    storage: "512GB",
    price: 75000
};

for (const key in laptop) {
    console.log(key, laptop[key]);
}
```

**Output**

```
brand Dell
ram 16GB
storage 512GB
price 75000
```

---

## 🔑 Accessing Only Keys

```javascript
for (const key in laptop) {
    console.log(key);
}
```

**Output** → `brand` `ram` `storage` `price`

---

## 📦 Accessing Only Values

```javascript
for (const key in laptop) {
    console.log(laptop[key]);
}
```

**Output** → `Dell` `16GB` `512GB` `75000`

---

## 📊 for...in vs Object Methods

| | `for...in` | `Object.keys()` | `Object.entries()` |
|--|:----------:|:---------------:|:-----------------:|
| Returns | Keys one by one | Array of keys | Array of pairs |
| Inherited props | ✅ Includes | ❌ Excludes | ❌ Excludes |
| Use case | Simple iteration | Array operations | Key + value |

---

## 📊 for...in vs for...of

| | `for...in` | `for...of` |
|--|:----------:|:---------:|
| Used for | Objects (keys) | Arrays, strings |
| Gives | Keys | Values |

---

## 🛡️ Inherited Properties Warning

`for...in` also iterates over **inherited properties**. Use `hasOwnProperty()` to filter.

```javascript
for (const key in laptop) {
    if (laptop.hasOwnProperty(key)) {
        console.log(key, laptop[key]);
    }
}
```

---

## ✅ Best Practices

✅ Use `for...in` for simple object iteration.

✅ Prefer `Object.entries()` with `for...of` for cleaner code.

```javascript
for (const [key, value] of Object.entries(laptop)) {
    console.log(key, value);
}
```

---

## ⚠️ Common Mistakes

### ❌ Using for...in on arrays

```javascript
const colors = ["Red", "Green", "Blue"];

for (const key in colors) {
    console.log(key); // 0, 1, 2 — indices, not values ❌
}
```

✅ Use `for...of` for arrays.

```javascript
for (const color of colors) {
    console.log(color); // Red, Green, Blue ✅
}
```

---

### ❌ Forgetting bracket notation

```javascript
for (const key in laptop) {
    console.log(laptop.key);  // ❌ undefined
    console.log(laptop[key]); // ✅ correct
}
```

## 🌍 Real-world Example

```javascript
const user = {
    name: "Rahul",
    email: "rahul@example.com",
    role: "admin",
    age: 26
};

for (const key in user) {
    console.log(`${key}: ${user[key]}`);
}
```

**Output**

```
name: Rahul
email: rahul@example.com
role: admin
age: 26
```

## 💡 Interview Definition

> The `for...in` loop iterates over the **enumerable property keys** of an object. On each iteration, the loop variable holds the current key as a string, and the value can be accessed using bracket notation. Unlike `Object.keys()`, `for...in` also includes **inherited properties**, so `hasOwnProperty()` should be used when needed.
