# 🟦 for...in Loop

---

## 📖 Definition

The for...in loop iterates over the property names of an object.

---

## ❓ Why it was introduced

It is useful when working with object properties.

---

## ✍️ Syntax

```javascript
for (let key in user) {
    console.log(key);
}
```

---

## 💻 Code Example

```javascript
const user = { name: "Rahul", age: 25 };
for (let key in user) {
    console.log(key, user[key]);
}
```

---

## 🧩 Line-by-line Explanation

- key stores each property name.
- user[key] accesses the matching value.
