# 🟫 this Keyword

---

## 📖 Definition

`this` refers to the **object that is currently executing the function**. Inside an object method, `this` refers to the object itself, allowing you to access its own properties.

```javascript
const person = {
    name: "Rahul",
    greet() {
        console.log(this.name);
    }
};

person.greet(); // Rahul
```

---

## ❓ Why do we need this?

Without `this` you cannot access the object's own properties from inside a method.

```javascript
const person = {
    name: "Rahul",
    greet() {
        console.log(name); // ❌ looks for global variable
    }
};
```

```javascript
const person = {
    name: "Rahul",
    greet() {
        console.log(this.name); // ✅ accesses object property
    }
};
```

## 📊 this in Different Contexts

| Context | Value of `this` |
|---------|:--------------:|
| 🗂️ Object method | The object |
| ⚙️ Regular function | `undefined` (strict) or global |
| ➡️ Arrow function | Inherited from outer scope |
| 🌐 Global scope | `window` (browser) |

---

## ⚠️ this in Arrow Functions

Arrow functions do **NOT** have their own `this`. They **inherit** it from the surrounding scope.

```javascript
const person = {
    name: "Rahul",
    greet: () => {
        console.log(this.name); // ❌ undefined
    }
};

person.greet();
```

> ⚠️ Avoid using arrow functions as object methods when you need `this`.

---

## 🔄 Regular Method vs Arrow Function

```javascript
// ✅ Regular method — this works correctly
const person = {
    name: "Rahul",
    greet() {
        console.log(this.name); // Rahul
    }
};

// ❌ Arrow function — this does not refer to the object
const person = {
    name: "Rahul",
    greet: () => {
        console.log(this.name); // undefined
    }
};
```

---

## ✅ Best Practices

✅ Use regular methods when you need `this` inside an object.

```javascript
const car = {
    brand: "BMW",
    print() {
        console.log(this.brand);
    }
};
```

✅ Use shorthand method syntax.

```javascript
print() { }       // ✅ shorthand
print: function() { } // verbose
```

---

## ⚠️ Common Mistakes

### ❌ Using arrow function as a method

```javascript
const book = {
    title: "Node",
    print: () => {
        console.log(this.title); // ❌ undefined
    }
};
```

```javascript
const book = {
    title: "Node",
    print() {
        console.log(this.title); // ✅ Node
    }
};
```

---

### ❌ Accessing property without this

```javascript
const car = {
    brand: "BMW",
    print() {
        console.log(brand); // ❌ ReferenceError
    }
};
```

```javascript
const car = {
    brand: "BMW",
    print() {
        console.log(this.brand); // ✅ BMW
    }
};
```
