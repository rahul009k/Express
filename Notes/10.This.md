# this Keyword

## 📖 Definition

`this` refers to the object that is currently executing the function. Inside an object method, `this` refers to the object itself, allowing you to access its properties.

```javascript
const person = {
    name: "Rahul",
    greet() {
        console.log(this.name);
    }
};

person.greet();
```

Output

```
Rahul
```

---

# Why do we need this?

Without `this` you cannot access the object's own properties from inside a method.

Wrong

```javascript
const person = {
    name: "Rahul",
    greet() {
        console.log(name);
    }
};
```

This would look for a global variable `name`, not the object's property.

Correct

```javascript
const person = {
    name: "Rahul",
    greet() {
        console.log(this.name);
    }
};
```

---

# this Inside an Object Method

```javascript
const person = {
    name: "Rahul",

    greet() {
        console.log(this.name);
    }
};

person.greet();
```

Output

```
Rahul
```

`this.name` refers to `person.name`.

---

# this with Multiple Properties

```javascript
const car = {
    brand: "BMW",
    model: "X5",
    year: 2024,

    print() {
        console.log(this.brand);
        console.log(this.model);
        console.log(this.year);
    }
};

car.print();
```

Output

```
BMW
X5
2024
```

# this in Different Contexts

| Context | Value of this |
|---------|--------------|
| Object method | The object |
| Regular function | `undefined` (strict) or global |
| Arrow function | Inherited from outer scope |
| Global scope | Global object (`window` in browser) |

---

# this in Arrow Functions

Arrow functions do NOT have their own `this`. They inherit `this` from the surrounding scope.

```javascript
const person = {
    name: "Rahul",
    greet: () => {
        console.log(this.name);
    }
};

person.greet();
```

Output

```
undefined
```

> Avoid using arrow functions as object methods when you need `this`.

---

# this in Regular Method vs Arrow Function

Regular method — `this` works correctly.

```javascript
const person = {
    name: "Rahul",
    greet() {
        console.log(this.name);
    }
};

person.greet();
```

Output

```
Rahul
```

Arrow function — `this` does not refer to the object.

```javascript
const person = {
    name: "Rahul",
    greet: () => {
        console.log(this.name);
    }
};

person.greet();
```

Output

```
undefined
```

---

# Best Practices

✅ Use regular methods (not arrow functions) when you need `this` inside an object.

```javascript
const car = {
    brand: "BMW",
    print() {
        console.log(this.brand);
    }
};
```

Use shorthand method syntax.

```javascript
print() { }
```

Instead of

```javascript
print: function() { }
```

# Common Mistakes

## Using arrow function as a method

Wrong

```javascript
const book = {
    title: "Node",
    print: () => {
        console.log(this.title);
    }
};
```

Output

```
undefined
```

Correct

```javascript
const book = {
    title: "Node",
    print() {
        console.log(this.title);
    }
};
```

---

## Accessing property without this

Wrong

```javascript
const car = {
    brand: "BMW",
    print() {
        console.log(brand);
    }
};
```

Correct

```javascript
const car = {
    brand: "BMW",
    print() {
        console.log(this.brand);
    }
};
```

# Real-world Example

```javascript
const user = {
    name: "Rahul",
    role: "Admin",
    balance: 5000,

    getInfo() {
        console.log("Name:", this.name);
        console.log("Role:", this.role);
        console.log("Balance:", this.balance);
    }
};

user.getInfo();
```

Output

```
Name: Rahul
Role: Admin
```
