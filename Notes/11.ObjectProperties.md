# 🟦 Object Properties

---

## 📖 Definition

An **object** is a collection of **key-value pairs**. Each key is called a property, and the value can be any data type. You can access properties using **dot notation** or **bracket notation**.

```javascript
const student = {
    id: 1,
    name: "Rahul",
    course: "JavaScript",
    marks: 95
};
```

---

## ❓ Why do we need Objects?

Instead of storing related data in separate variables:

```javascript
let id = 1;
let name = "Rahul";
let course = "JavaScript";
```

You group them in **one object**:

```javascript
const student = {
    id: 1,
    name: "Rahul",
    course: "JavaScript"
};
```

---

## 🔵 Dot Notation

The most common way to access properties.

```javascript
console.log(student.id);
console.log(student.name);
console.log(student.course);
console.log(student.marks);
```

**Output**

```
1
Rahul
JavaScript
95
```

---

## 🟠 Bracket Notation

Used when the property name is a string or stored in a variable.

```javascript
console.log(student["name"]);
console.log(student["id"]);
console.log(student["course"]);
console.log(student["marks"]);
```

**Output**

```
Rahul
1
JavaScript
95
```

---

## 🔑 Dynamic Property Access

When the property name is stored in a **variable**, you must use bracket notation.

```javascript
const employee = {
    id: 101,
    name: "Rahul",
    department: "IT",
    salary: 50000
};

const property = "department";

console.log(employee.property);   // ❌ undefined
console.log(employee[property]);  // ✅ IT
```

> ⚠️ `employee.property` looks for a key literally named `property` — which does not exist.
> ✅ `employee[property]` uses the **value** of the variable `property`, which is `"department"`.

---

## 📊 Dot vs Bracket Notation

| | Dot Notation | Bracket Notation |
|--|:-----------:|:---------------:|
| Syntax | `obj.key` | `obj["key"]` |
| Dynamic keys | ❌ | ✅ |
| Readability | ✅ | Less readable |
| Use case | Known keys | Dynamic / variable keys |

---

## ✅ Best Practices

✅ Use dot notation by default.

```javascript
console.log(student.name);
```

✅ Use bracket notation only when the key is dynamic.

```javascript
const key = "name";
console.log(student[key]);
```

---

## ⚠️ Common Mistakes

### ❌ Using dot notation with a variable key

```javascript
const key = "name";
console.log(student.key);  // ❌ undefined
console.log(student[key]); // ✅ Rahul
```

---

### ❌ Accessing a non-existent property

```javascript
console.log(student.email); // undefined — no error, just undefined
```

---

## 🌍 Real-world Example

```javascript
const product = {
    id: 1,
    name: "Laptop",
    brand: "Dell",
    price: 75000
};

console.log(product.name);   // Laptop
console.log(product.price);  // 75000

const field = "brand";
console.log(product[field]); // Dell
```
