# Array.some()

## 📖 Definition

`some()` is an array method that checks whether **at least one** element in the array satisfies a given condition. It returns `true` if any element passes, and `false` if none do.

```javascript
array.some(callback)
```

---

# Why do we need some()?

When you want to know if any element in an array meets a condition — without needing to find which one.

Without `some()`

```javascript
let found = false;

for (let i = 0; i < marks.length; i++) {
    if (marks[i] > 90) {
        found = true;
        break;
    }
}
```

With `some()`

```javascript
const found = marks.some(num => num > 90);
```

---

# Syntax

```javascript
const result = array.some(element => condition);
```

---

# Example

```javascript
const marks = [65, 72, 88, 91, 54];

let result = marks.some(num => num > 90);

console.log(result);
```

Output

```
true
```

`91` is greater than `90`, so `some()` returns `true`.

---

# Returns false When No Element Matches

```javascript
const marks = [65, 72, 88, 54];

let result = marks.some(num => num > 90);

console.log(result);
```

Output

```
false
```

---

# some() Stops at First Match

`some()` stops iterating as soon as it finds the first element that passes the condition.

```javascript
const numbers = [1, 2, 3, 4, 5];

const result = numbers.some(n => {
    console.log("Checking:", n);
    return n > 3;
});

console.log(result);
```

Output

```
Checking: 1
Checking: 2
Checking: 3
Checking: 4
true
```

Stops at `4` because it is the first element greater than `3`.

---

# some() vs every()

| | some() | every() |
|--|-------|--------|
| Returns true when | At least one passes | All pass |
| Returns false when | None pass | At least one fails |
| Stops early | At first true | At first false |

---

# some() vs includes()

| | some() | includes() |
|--|-------|-----------|
| Condition | Custom callback | Exact value match |
| Use case | Complex conditions | Simple value check |

---

# Best Practices

✅ Use `some()` to check if any element meets a condition.

```javascript
const hasHighScore = marks.some(m => m > 90);
```

Use `every()` when all elements must meet the condition.

```javascript
const allPassed = marks.every(m => m >= 50);
```

---

# Common Mistakes

## Confusing some() with every()

`some()` — at least one must pass.

`every()` — all must pass.

```javascript
const marks = [65, 72, 88, 91, 54];

console.log(marks.some(m => m > 50));

console.log(marks.every(m => m > 50));
```

Output

```
true
false
```

`54` fails the `every()` check.

---

## Expecting the matching element

`some()` returns `true` or `false`, not the element.

Use `find()` if you need the actual element.

---

# Real-world Example

```javascript
const orders = [
    { id: 1, status: "delivered" },
    { id: 2, status: "pending" },
    { id: 3, status: "delivered" }
];

const hasPending = orders.some(order => order.status === "pending");

if (hasPending) {
    console.log("There are pending orders");
} else {
    console.log("All orders are delivered");
}
```

Output

```
There are pending orders
```
