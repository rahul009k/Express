# 🟦 for Loop

---

## 📖 Definition

A for loop repeats a block of code a fixed number of times.

---

## ❓ Why it was introduced

It is helpful for repeated tasks and iteration.

---

## ✍️ Syntax

```javascript
for (let i = 0; i < 3; i++) {
    console.log(i);
}
```

---

## 💻 Code Example

```javascript
for (let i = 0; i < 3; i++) {
    console.log(i);
}
```

---

## 🧩 Line-by-line Explanation

- i starts at 0 and increases after each iteration.
