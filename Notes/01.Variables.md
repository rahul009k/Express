# Variables

## 📖 Definition

A variable is a named container used to store data in memory. It allows us to save values and reuse or modify them throughout a program.

Think of a variable as a labelled box.

```
Name → Rahul
Age  → 24
City → Delhi
```

Instead of remembering the actual value, we use the variable name.

---

# Why do we need variables?

Imagine writing:

```javascript
console.log("Rahul");
console.log("Rahul");
console.log("Rahul");
console.log("Rahul");
```

If the name changes, you must update every line.

Using a variable:

```javascript
let name = "Rahul";

console.log(name);
console.log(name);
console.log(name);
console.log(name);
```

Now changing one line updates the value everywhere.

---

# Variable Declaration

JavaScript provides three ways to declare variables.

```javascript
var name = "Rahul";

let age = 24;

const country = "India";
```

---

# var

`var` was introduced in the first version of JavaScript.

Example

```javascript
var city = "Delhi";
console.log(city);
```

### Characteristics

- Function scoped
- Can be redeclared
- Can be reassigned
- Hoisted
- Avoid using in modern JavaScript

Example

```javascript
var name = "Rahul";
var name = "Amit";

console.log(name);
```

Output

```
Amit
```

---

# let

Introduced in ES6 (2015).

Example

```javascript
let age = 24;

age = 25;

console.log(age);
```

Output

```
25
```

### Characteristics

- Block scoped
- Cannot be redeclared
- Can be reassigned
- Preferred for changing values

---

# const

Used for values that should never be reassigned.

Example

```javascript
const pi = 3.14159;

console.log(pi);
```

Output

```
3.14159
```

Trying to reassign

```javascript
const pi = 3.14;

pi = 10;
```

Output

```
TypeError
```

---

# Block Scope

Variables declared using `let` and `const` exist only inside the block.

```javascript
{
    let message = "Hello";
}

console.log(message);
```

Output

```
ReferenceError
```

---

# Function Scope

```javascript
function test() {

    var name = "Rahul";

    console.log(name);
}

console.log(name);
```

Output

```
ReferenceError
```

`var` is visible only inside the function where it is declared.

---

# Hoisting

JavaScript moves declarations to the top before executing code.

Example

```javascript
console.log(a);

var a = 10;
```

Internally JavaScript treats it like

```javascript
var a;

console.log(a);

a = 10;
```

Output

```
undefined
```

---

# Hoisting with let

```javascript
console.log(age);

let age = 24;
```

Output

```
ReferenceError
```

---

# Hoisting with const

```javascript
console.log(country);

const country = "India";
```

Output

```
ReferenceError
```

---

# Temporal Dead Zone (TDZ)

The period between entering a scope and declaring a `let` or `const` variable is called the **Temporal Dead Zone**.

Example

```javascript
console.log(name);

let name = "Rahul";
```

The variable exists but cannot be accessed before its declaration.

# Naming Rules

✅ Valid

```javascript
let firstName;

let _name;

let $price;

let age24;
```

❌ Invalid

```javascript
let 123name;

let first-name;

let let;
```

---

# Naming Conventions

Good

```javascript
let firstName;

let totalAmount;

let isLoggedIn;
```

Bad

```javascript
let x;

let abc;

let a1;
```

Use meaningful names.

---

# When should I use var, let, and const?

| Keyword | Redeclare | Reassign | Scope |
|----------|-----------|----------|-------|
| var | ✅ | ✅ | Function |
| let | ❌ | ✅ | Block |
| const | ❌ | ❌ | Block |

---

# Best Practices

✅ Prefer `const` by default.

```javascript
const company = "OpenAI";
```

Use `let` only when the value needs to change.

```javascript
let score = 0;

score++;
```

Avoid `var` in modern JavaScript.

---

# Common Mistakes

### Using var everywhere

```javascript
var age = 20;
```

Instead

```javascript
let age = 20;
```

---

### Using const for changing values

Wrong

```javascript
const count = 1;

count++;
```

Correct

```javascript
let count = 1;

count++;
```

---

### Poor variable names

Bad

```javascript
let x = 100;
```

Better

```javascript
let employeeSalary = 100;
```

---

# Real-world Example

```javascript
const userName = "Rahul";

let balance = 5000;

balance += 1000;

console.log(userName);

console.log(balance);
```

In modern JavaScript, `const` is preferred by default, `let` is used when reassignment is required, and `var` is generally avoided because of function scope and hoisting behaviour.
