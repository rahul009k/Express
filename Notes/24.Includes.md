# 🟥 Array.includes()

---

## 📖 Definition

`includes()` is an array method that checks whether a **specific value exists** in an array. It returns `true` if found, and `false` if not.

```javascript
array.includes(value)
```

---

## 💻 Example

```javascript
const languages = ["Java", "C#", "Python", "JavaScript"];

console.log(languages.includes("JavaScript"));
```

**Output** → `true`

---

## ❌ Value Not Found

```javascript
console.log(languages.includes("Go"));
```

**Output** → `false`

---

## ⚠️ Case Sensitive

```javascript
console.log(languages.includes("javascript")); // false ⚠️
console.log(languages.includes("JavaScript")); // true ✅
```

> `includes()` is **case-sensitive**. `"JavaScript"` and `"javascript"` are different.

---

## 🔢 With Start Index

```javascript
const numbers = [1, 2, 3, 4, 5];

console.log(numbers.includes(3, 3)); // false — starts searching from index 3
```

---

## 📊 includes() vs indexOf()

| | `includes()` | `indexOf()` |
|--|:-----------:|:-----------:|
| Returns | `true` / `false` | Index or `-1` |
| Use case | Check existence | Find position |
| NaN check | ✅ Works | ❌ Does not work |

---

## ✅ Best Practices

✅ Use `includes()` for simple existence checks.

```javascript
if (languages.includes("JavaScript")) {
    console.log("JavaScript is in the list");
}
```

✅ Use `indexOf()` when you need the position.

---

## ⚠️ Common Mistakes

### ❌ Case sensitivity

```javascript
languages.includes("javascript"); // false ⚠️ — capital J matters
```

---

### ❌ Using includes() on objects

```javascript
const users = [{ name: "Rahul" }, { name: "Amit" }];

console.log(users.includes({ name: "Rahul" })); // false ⚠️
```

> Objects are compared by **reference**, not by value. Use `find()` instead.

---

## 🌍 Real-world Example

```javascript
const allowedRoles = ["admin", "editor", "moderator"];

const userRole = "admin";

if (allowedRoles.includes(userRole)) {
    console.log("Access granted ✅");
} else {
    console.log("Access denied ❌");
}
```

**Output** → `Access granted ✅`
