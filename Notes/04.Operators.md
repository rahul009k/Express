# Operators

## 📖 Definition

An operator is a symbol that performs an operation on one or more values (called operands). JavaScript has several types of operators for arithmetic, comparison, and logical operations.

```javascript
let x = 10;
let y = 20;

console.log(x + y);
```

Output

```
30
```

---

# Why do we need Operators?

Operators allow you to perform calculations, compare values, and make decisions in your code.

# Strict vs Loose Equality

`==` compares values only (type coercion happens).

`===` compares both value and type (no type coercion).

```javascript
let x = 10;

y = "20";

console.log(x == y);
```

Output

```
false
```

```javascript
console.log(x === y);
```

Output

```
false
```

Another example

```javascript
console.log(10 == "10");
```

Output

```
true
```

```javascript
console.log(10 === "10");
```

Output

```
false
```

> Always prefer `===` to avoid unexpected type coercion.

# Logical Operators

Used to combine multiple conditions.

| Operator | Description | Example | Output |
|----------|-------------|---------|--------|
| && | Logical AND | true && false | false |
| \|\| | Logical OR | true \|\| false | true |
| ! | Logical NOT | !true | false |

---

## Logical AND

Returns `true` only if both conditions are true.

```javascript
const isLoggedIn = true;
const isAdmin = false;

console.log(isLoggedIn && isAdmin);
```

Output

```
false
```

---

## Logical OR

Returns `true` if at least one condition is true.

```javascript
console.log(isLoggedIn || isAdmin);
```

Output

```
true
```

---

## Logical NOT

Reverses the boolean value.

```javascript
console.log(!isLoggedIn);
```

Output

```
false
```

# Best Practices

✅ Always use `===` instead of `==`.

```javascript
if (age === 18) { }
```

Instead of

```javascript
if (age == 18) { }
```

Use parentheses to make complex conditions readable.

```javascript
if ((isLoggedIn && isAdmin) || isSuperUser) { }
```

---

# Common Mistakes

## Using == instead of ===

Wrong

```javascript
if (age == "18") { }
```

Correct

```javascript
if (age === 18) { }
```

---

## Confusing = with ==

Wrong

```javascript
if (x = 10) { }
```

This assigns 10 to x instead of comparing.

Correct

```javascript
if (x === 10) { }
```
