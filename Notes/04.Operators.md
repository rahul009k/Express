# 🟧 Operators

---

## 📖 Definition

An **operator** is a symbol that performs an operation on one or more values (called operands). JavaScript has operators for arithmetic, comparison, and logical operations.

```javascript
let x = 10;
let y = 20;

console.log(x + y); // 30
```

---

## ❓ Why do we need Operators?

Operators allow you to perform **calculations**, **compare values**, and **make decisions** in your code.

---

## 🗂️ Categories of Operators

```
Operators
│
├── ➕ Arithmetic   → Math calculations
├── ⚖️ Comparison  → Compare values
└── 🔗 Logical     → Combine conditions
```

## ➕ Arithmetic Operators

Used to perform mathematical calculations.

```javascript
let x = 10;
let y = 20;
```

| Operator | Description | Example | Output |
|:--------:|-------------|---------|:------:|
| `+` | Addition | `x + y` | `30` |
| `-` | Subtraction | `x - y` | `-10` |
| `*` | Multiplication | `x * y` | `200` |
| `/` | Division | `x / y` | `0.5` |
| `%` | Modulus (remainder) | `x % y` | `10` |

---

console.log(x + y);

**Output** → `30`

**Output** → `-10`

### ✖️ Multiplication

## ⚖️ Comparison Operators

Used to compare two values. Always returns `true` or `false`.

| Operator | Description | Example | Output |
|:--------:|-------------|---------|:------:|
| `>` | Greater than | `x > y` | `false` |
| `<` | Less than | `x < y` | `true` |
| `>=` | Greater than or equal | `x >= y` | `false` |
| `<=` | Less than or equal | `x <= y` | `true` |
| `==` | Equal to (loose) | `x == y` | `false` |
| `!=` | Not equal to | `x != y` | `true` |

---

## 🔍 Strict vs Loose Equality

`==` compares **values only** (type coercion happens).

`===` compares **both value and type** (no type coercion).

```javascript
let x = 10;
y = "20";

console.log(x == y);   // false
console.log(x === y);  // false
```

```javascript
console.log(10 == "10");  // true  ⚠️ type coercion
console.log(10 === "10"); // false ✅ strict check
```

> ⚠️ Always prefer `===` to avoid unexpected type coercion.

---

## 🔗 Logical Operators

Used to combine multiple conditions.

| Operator | Description | Example | Output |
|:--------:|-------------|---------|:------:|
| `&&` | Logical AND | `true && false` | `false` |
| `\|\|` | Logical OR | `true \|\| false` | `true` |
| `!` | Logical NOT | `!true` | `false` |

---

### 🔗 Logical AND — both must be true

```javascript
const isLoggedIn = true;
const isAdmin = false;

console.log(isLoggedIn && isAdmin);
```

**Output** → `false`

---

### 🔗 Logical OR — at least one must be true

```javascript
console.log(isLoggedIn || isAdmin);
```

**Output** → `true`

---

### 🔗 Logical NOT — reverses the value

```javascript
console.log(!isLoggedIn);
```

**Output** → `false`

---

## ✅ Best Practices

✅ Always use `===` instead of `==`.

```javascript
if (age === 18) { }
```

✅ Use parentheses to make complex conditions readable.

```javascript
if ((isLoggedIn && isAdmin) || isSuperUser) { }
```

---

## ⚠️ Common Mistakes

### ❌ Using == instead of ===

```javascript
if (age == "18") { }  // ❌ type coercion risk
if (age === 18) { }   // ✅ strict check
```

---

### ❌ Confusing = with ==

```javascript
if (x = 10) { }  // ❌ assigns 10, always true
if (x === 10) { } // ✅ compares
```

---

## 🌍 Real-world Example

```javascript
const userAge = 20;
const hasAccount = true;
const isVerified = false;

console.log(userAge >= 18);           // true
console.log(hasAccount && isVerified); // false
console.log(hasAccount || isVerified); // true
console.log(!isVerified);              // true
```
