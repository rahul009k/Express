# Array.filter()

## 📖 Definition

`filter()` is an array method that creates a **new array** containing only the elements that pass a given condition (return `true` from the callback). It does not modify the original array.

```javascript
array.filter(callback)
```

---

# Why do we need filter()?

When you want to extract only certain elements from an array based on a condition.

Without `filter()`

```javascript
const numbers = [5, 15, 25, 35, 10, 40];
const result = [];

for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] > 20) {
        result.push(numbers[i]);
    }
}
```

With `filter()`

```javascript
const result = numbers.filter(num => num > 20);
```

---

# Syntax

```javascript
const newArray = array.filter(element => condition);
```

---

# Example

```javascript
const numbers = [5, 15, 25, 35, 10, 40];

const result = numbers.filter(num => num > 20);

console.log(result);
```

Output

```
[ 25, 35, 40 ]
```

---

# Another Example — Even Numbers

```javascript
const numbers = [1, 2, 3, 4, 5, 6];

const result = numbers.filter(num => num % 2 === 0);

console.log(result);
```

Output

```
[ 2, 4, 6 ]
```

---

# Original Array is Not Modified

```javascript
const numbers = [5, 15, 25, 35, 10, 40];

const result = numbers.filter(num => num > 20);

console.log(numbers);

console.log(result);
```

Output

```
[ 5, 15, 25, 35, 10, 40 ]
[ 25, 35, 40 ]
```

# Filtering Objects

```javascript
const users = [
    { name: "Rahul", age: 26, active: true },
    { name: "Amit", age: 17, active: false },
    { name: "Neha", age: 22, active: true }
];

const activeUsers = users.filter(user => user.active);

console.log(activeUsers);
```

Output

```
[
  { name: 'Rahul', age: 26, active: true },
  { name: 'Neha', age: 22, active: true }
]
```

---

# Filtering Adults

const adults = users.filter(user => user.age >= 18);

```

```

  { name: 'Rahul', age: 26, active: true },

# map() vs filter()

| | map() | filter() |
|--|------|---------|
| Purpose | Transform elements | Select elements |
| Returns | New array (same length) | New array (shorter or equal) |
| Callback returns | Transformed value | true / false |

---

# Chaining map() and filter()

```javascript
const numbers = [1, 2, 3, 4, 5, 6];

const result = numbers
    .filter(n => n % 2 === 0)
    .map(n => n * 10);

console.log(result);
```

Output

```
[ 20, 40, 60 ]
```

---

# Best Practices

✅ Use `filter()` to extract elements that match a condition.

```javascript
const activeUsers = users.filter(user => user.active);
```

Chain `filter()` with `map()` for powerful transformations.

```javascript
users.filter(u => u.active).map(u => u.name);
```

---

# Common Mistakes

## Forgetting that filter returns a new array

`filter()` does not modify the original.

```javascript
numbers.filter(n => n > 20);

console.log(numbers);
```

Output

```
[ 5, 15, 25, 35, 10, 40 ]
```

You must store the result.

```javascript
const result = numbers.filter(n => n > 20);
```

---

## Returning a value instead of a condition

Wrong

```javascript
const result = numbers.filter(n => n * 2);
```

This keeps all non-zero elements (truthy), not what you intended.

Correct

```javascript
const result = numbers.filter(n => n > 20);
```

# Real-world Example

```javascript
const products = [
    { name: "Laptop", price: 75000, inStock: true },
    { name: "Mouse", price: 500, inStock: false },
    { name: "Keyboard", price: 1500, inStock: true }
];

const available = products.filter(p => p.inStock);

console.log(available);
```

Output

```
[
  { name: 'Laptop', price: 75000, inStock: true },
  { name: 'Keyboard', price: 1500, inStock: true }
]
```
