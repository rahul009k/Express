# for...of Loop

## 📖 Definition

The `for...of` loop is used to iterate over the values of an iterable (arrays, strings, etc.). On each iteration, the loop variable holds the current value directly — no index needed.

```javascript
for (const item of iterable) {
    // code
}
```

---

# Why do we need for...of?

The `for` loop requires managing an index variable.

```javascript
for (let i = 0; i < names.length; i++) {
    console.log(names[i]);
}
```

`for...of` is cleaner when you only need the values.

```javascript
for (const name of names) {
    console.log(name);
}
```

---

# Syntax

```javascript
for (const variableName of arrayName) {
    console.log(variableName);
}
```

---

# Example

```javascript
const names = ["Rahul", "Amit", "Neha", "Priya"];

for (const name of names) {
    console.log(name);
}
```

Output

```
Rahul
Amit
Neha
Priya
```

---

# for...of vs for Loop

| | for loop | for...of |
|--|---------|---------|
| Index access | ✅ | ❌ |
| Value access | ✅ | ✅ |
| Syntax | Verbose | Clean |
| Use case | When index needed | When only value needed |

> Use `for...of` when you only need values.
> Use `for` loop when you need the index as well.

---

# for...of vs for...in

| | for...of | for...in |
|--|---------|---------|
| Used for | Arrays, strings, iterables | Objects |
| Gives | Values | Keys |

---

# Looping Over a String

```javascript
const word = "Rahul";

for (const char of word) {
    console.log(char);
}
```

Output

```
R
a
h
u
l
```

# Looping Over an Array of Objects

```javascript
const users = [
    { name: "Rahul", age: 26 },
    { name: "Amit", age: 24 }
];

for (const user of users) {
    console.log(user.name, user.age);
}
```

Output

```
Rahul 26
Amit 24
```

---

# Best Practices

✅ Use `for...of` when you only need values from an array.

```javascript
for (const name of names) {
    console.log(name);
}
```

Use `for` loop when you need the index.

```javascript
for (let i = 0; i < names.length; i++) {
    console.log(i, names[i]);
}
```

Use `for...in` for objects.

```javascript
for (const key in object) {
    console.log(key, object[key]);
}
```

---

# Common Mistakes

## Using for...of on objects

Wrong

```javascript
const user = { name: "Rahul", age: 26 };

for (const item of user) {
    console.log(item);
}
```

Output

```
TypeError: user is not iterable
```

Correct — use `for...in` for objects.

```javascript
for (const key in user) {
    console.log(key, user[key]);
}
```

---

## Expecting index from for...of

`for...of` does not give you the index.

```javascript
for (const name of names) {
    console.log(name);
}
```

If you need the index, use `entries()`.

```javascript
for (const [index, name] of names.entries()) {
    console.log(index, name);
}
```

# Real-world Example

```javascript

    console.log("Processing:", product);
```

# Interview Definition

> The `for...of` loop iterates over the values of any iterable such as arrays and strings. It is cleaner than the `for` loop when you only need values and do not need the index. For objects, `for...in` should be used instead. To get both index and value, use `array.entries()` with `for...of`.
