# 🟦 JavaScript Promises

---

## 📖 Definition

A **Promise** is an object used to handle asynchronous operations in JavaScript.

It helps us manage tasks like:
- fetching data from a server
- reading a file
- waiting for a timer
- handling API responses

Instead of writing confusing callback code, promises make the flow easier to read.

---

## 🔄 Promise States

A promise can be in one of these states:

- **Pending** → still running
- **Fulfilled** → completed successfully
- **Rejected** → failed with an error

---

## ✍️ Basic Syntax

```javascript
const promise = new Promise((resolve, reject) => {
    resolve("Hello Rahul");
});
```

- `resolve()` means the promise was successful
- `reject()` means the promise failed

---

## ✅ Using `.then()` and `.catch()`

```javascript
const promise1 = new Promise((resolve, reject) => {
    reject("Server Error");
});

promise1
    .then(result => {
        console.log(result);
    })
    .catch(error => {
        console.log(error);
    });
```

### Explanation
- `.then()` runs when the promise is successful
- `.catch()` runs when the promise fails

---

## 🔗 Promise Chaining

You can connect multiple `.then()` methods one after another.

```javascript
Promise.resolve(20)
    .then(result => result + 10)
    .then(result => result * 2)
    .then(result => console.log(result));
```

### Output
```javascript
60
```

---

## ⚠️ Error Handling in Promise Chain

```javascript
Promise.resolve(10)
    .then(result => {
        console.log(result);
        throw new Error("Failed");
    })
    .then(result => {
        console.log(result);
    })
    .catch(error => {
        console.log(error.message);
    });
```

### Explanation
- The first `.then()` runs and prints `10`
- Then it throws an error
- The next `.then()` is skipped
- `.catch()` handles the error

---

## ⏰ Promise with `setTimeout()`

```javascript
const promise5 = new Promise((resolve) => {
    setTimeout(() => {
        resolve("Data Loaded");
    }, 2000);
});

console.log("Start");
promise5.then(result => {
    console.log(result);
});
console.log("End");
```

### Output Order
```javascript
Start
End
Data Loaded
```

This happens because the timer runs later, after the main code finishes.

---

## 🧠 Important Concept

Promises are used for asynchronous work.

A simple way to remember:
- `.then()` → success
- `.catch()` → failure
- `.finally()` → always runs at the end

---

## 📌 Summary

Promises make JavaScript code easier to read when working with delayed operations.

Use them when you want to:
- wait for something
- handle success
- handle errors
- chain multiple steps
