# 🟥 Array.find()

---

## 📖 Definition

`find()` is an array method that returns the **first element** that satisfies a given condition. If no element matches, it returns `undefined`.

```javascript
array.find(callback)
```

> 💡 `find()` returns **one element**, not an array.

---

## 💻 Example

```javascript
const fruits = ["Apple", "Banana", "Mango", "Melon", "Orange"];

const result = fruits.find(fruit => fruit.startsWith("M"));

console.log(result);
```

**Output** → `Mango`

> ⚠️ Only the **first match** is returned. `Melon` also starts with `M` but is not returned.

---

## ❓ Returns undefined if Not Found

```javascript
const result = fruits.find(fruit => fruit.startsWith("Z"));

console.log(result); // undefined
```

---

## 🔢 Finding in Numbers

```javascript
const numbers = [10, 25, 30, 45, 50];

const result = numbers.find(n => n > 30);

console.log(result); // 45
```

---

## 📦 Finding an Object

```javascript
const users = [
    { id: 1, name: "Rahul" },
    { id: 2, name: "Amit" },
    { id: 3, name: "Neha" }
];

const user = users.find(u => u.id === 2);

console.log(user); // { id: 2, name: 'Amit' }
```

---

## 📊 find() vs filter()

| | `find()` | `filter()` |
|--|:-------:|:---------:|
| Returns | First matching element | All matching elements |
| No match | `undefined` | Empty array `[]` |
| Use case | Find one item | Find multiple items |

---

## 📊 find() vs findIndex()

| | `find()` | `findIndex()` |
|--|:-------:|:------------:|
| Returns | The element | The index |
| No match | `undefined` | `-1` |

---

## ✅ Best Practices

✅ Use `find()` when you need only the **first matching element**.

✅ Always check for `undefined` after using `find()`.

```javascript
const user = users.find(u => u.id === 99);

if (user) {
    console.log(user.name);
} else {
    console.log("User not found");
}
```

---

## ⚠️ Common Mistakes

### ❌ Expecting an array from find()

```javascript
const result = fruits.find(f => f.startsWith("M"));
// "Mango" — not ['Mango', 'Melon'] ⚠️
```

Use `filter()` for all matches.

---

### ❌ Not handling undefined

```javascript
const result = fruits.find(f => f.startsWith("Z"));
console.log(result.length); // ❌ TypeError
```

```javascript
if (result) {
    console.log(result.length); // ✅ safe
}
```

## 🌍 Real-world Example

```javascript
const products = [
    { id: 101, name: "Laptop", price: 75000 },
    { id: 102, name: "Mouse", price: 500 },
    { id: 103, name: "Keyboard", price: 1500 }
];

const product = products.find(p => p.id === 102);

if (product) {
    console.log("Found:", product.name, "- Price:", product.price);
} else {
    console.log("Product not found");
}
```

**Output** → `Found: Mouse - Price: 500`

## 💡 Interview Definition

> `find()` is an array method that returns the **first element** that satisfies the provided condition. If no element matches, it returns `undefined`. Unlike `filter()`, which returns all matching elements, `find()` **stops at the first match**, making it more efficient when only one result is needed.
