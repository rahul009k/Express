# Arrow Functions

## 📖 Definition

An arrow function is a shorter syntax for writing functions introduced in ES6. Instead of the `function` keyword, you use `=>` (fat arrow). Arrow functions are cleaner and more concise.

```javascript
const add = (a, b) => {
    return a + b;
};
```

---

# Why do we need Arrow Functions?

Regular function syntax can be verbose.

```javascript
const add = function(a, b) {
    return a + b;
};
```

Arrow function is shorter and cleaner.

```javascript
const add = (a, b) => {
    return a + b;
};
```

---

# Syntax

```
const functionName = (parameters) => {
    return value;
};
```

---

# Converting Regular to Arrow Function

## 1. Add Function

Regular

```javascript
const add = function(a, b) {
    return a + b;
};
```

Arrow

```javascript
const add = (a, b) => {
    return a + b;
};

const ans = add(6, 10);

console.log(ans);
```

Output

```
16
```

---

## 2. Greet Function

Regular

```javascript
const greet = function(name) {
    return "Hello " + name;
};
```

Arrow

```javascript
const greet = (name) => {
    return "Hello " + name;
};

console.log(greet("Rahul"));
```

Output

```
Hello Rahul
```

# Single Parameter — Parentheses Optional

When there is only one parameter, you can omit the parentheses.

```javascript
const greet = name => {
    return "Hello " + name;
};
```

---

# No Parameters — Empty Parentheses Required

```javascript
const sayHello = () => {
    return "Hello!";
};
```

---

# Arrow vs Regular Function

| Feature | Regular Function | Arrow Function |
|---------|-----------------|----------------|
| Syntax | `function` keyword | `=>` |
| `this` binding | Own `this` | Inherits `this` |
| Hoisting | ✅ | ❌ |
| Use as method | ✅ | ⚠️ Avoid |

---

# Best Practices

✅ Use arrow functions for short, simple functions.

```javascript
const double = (n) => n * 2;
```

Use regular functions when you need `this` binding.

Use arrow functions for callbacks.

```javascript
numbers.map(n => n * 2);
```

# Common Mistakes

## Forgetting the return keyword

Wrong

```javascript
const add = (a, b) => {
    a + b;
};
```

Output

```
undefined
```

Correct

```javascript
const add = (a, b) => {
    return a + b;
};
```

---

## Using arrow functions as object methods

Wrong

```javascript
const person = {
    name: "Rahul",
    greet: () => {
        console.log(this.name);
    }
};
```

`this` will not refer to the object.

Correct

```javascript
const person = {
    name: "Rahul",
    greet() {
        console.log(this.name);
    }
};
```

# Real-world Example

```javascript
const calculateTax = (amount, rate) => {
    return amount * rate / 100;
};

const tax = calculateTax(1000, 18);

console.log(tax);
```

Output

```
180
```

# Interview Definition

> An arrow function is a concise syntax for writing functions in JavaScript using the `=>` operator. Arrow functions do not have their own `this` binding and are not hoisted. They are ideal for short functions and callbacks but should be avoided as object methods when `this` is needed.
